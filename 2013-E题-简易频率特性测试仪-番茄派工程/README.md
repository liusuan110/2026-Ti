# 2013 E题 简易频率特性测试仪 - 番茄派工程

本目录用于培训4：2013年全国大学生电子设计竞赛 E题《简易频率特性测试仪》。

当前只完成 CCS 空工程搭建，不包含扫频、正交信号、ADC、幅相计算、显示或按键等实际功能。

## 当前工程

- 主控：番茄派 MSPM0G3507
- 封装：LQFP-48 (PT)
- 工具链：TI Clang
- SDK：MSPM0 SDK 2.10.00.04
- 工程目录：`代码/FrequencyResponseTester`

## 方案调研

- [`联网调研与推荐方案.md`](联网调研与推荐方案.md)：历届公开方案、番茄派推荐架构、校准与误差预算、RLC参数和分阶段开发计划。

## 题目关键边界

- 正交扫频范围：1 MHz - 40 MHz，最小设置/步进 100 kHz
- 后续测试仪需测量幅频和相频特性
- 正交扫频信号源必须自制，不能直接使用商业 DDS 开发板或模块

这些要求仅作为后续开发边界，本次未实现任何业务功能。
