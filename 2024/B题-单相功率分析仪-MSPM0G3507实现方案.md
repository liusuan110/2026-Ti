# B 题《单相功率分析仪》—— MSPM0G3507 单芯片实现方案

> 目标:2024 模拟专题赛(TI杯)B 题 · 主控用你们的 **MSPM0G3507(番茄派)** · 单芯片、不要 FPGA、不要高速 ADC
> 整理日期:2026-06-02 · 指标已逐字核实(见第 1 节);本方案为工程设计建议,落地以实测为准

---

## 0. 速读(TL;DR)

- **B 题信号最高才 500Hz**(50Hz 基波 + 10 次谐波),**MSPM0G3507 的双 12 位 4MSPS 同步采样 ADC + 片上 CMSIS-DSP FFT 一颗就够**,无需 FPGA/高速 ADC。
- 前端用**无源互感器**(电压 ZMPT101B、电流 CT 多匝原边)——既隔离又几乎不耗电,守住 50mW。
- 三个成败点:**①整周期同步采样**(谐波/THD 准)、**②相位校准**(有功功率/功率因数 ±1% 全靠它)、**③50mW 功耗预算**(显示别用 TFT/常亮 OLED)。
- 代码骨架直接拿 [Raoxiuyu/TI-MSPM0G3507-code](https://github.com/Raoxiuyu/TI-MSPM0G3507-code) 的 ADC/DMA + FFT 例程改。

## 2. 总体架构 + 系统框图

```
 市电插座 220/250V ── 被测负载(≤4A, ≤500VA)
   │(电压并联取样)          │(电流串联取样)
   ▼                         ▼
电压互感器 ZMPT101B        电流互感器 CT(原边多匝)
   │ 无源隔离                │ 无源隔离
   ▼                         ▼ 负载电阻 R_burden(I→V)
 调理:衰减+AC耦合+1.65V偏置  调理:增益(可用内置PGA)+1.65V偏置+抗混叠RC
   │                         │
   ▼  ADC0   ┌── 同步触发 ──┐  ADC1  ▼
   └────────►│ MSPM0G3507  │◄────────┘
             │ 双ADC 同步采样(整周期锁相50Hz)
             │ 内置比较器:电压过零→频率/锁相
             │ CMSIS-DSP:RMS / P / S / Q / PF / FFT谐波 / THD
             └──────┬───────────────┬────────┘
                    ▼               ▼
        反射式段码LCD/STN(无背光)   UART 上位机(调试/抓波形)
                    
 供电:电池 → TPS62740 超低Iq Buck → 3.3V   (+ 直流电压/电流表测功耗接口)
```

**为什么这样分**:互感器无源隔离=安全+省电;MSPM0 双 ADC **硬件同步采样**是算有功功率/功率因数的前提(v、i 必须同一时刻采);过零检测用片上比较器做整周期锁相。

## 3. 关键设计决策

### 3.1 整周期同步采样(谐波/THD 准不准就看它)
- 用片上**比较器**检测电压过零 → 定时器捕获测出基波周期 T(跟踪 49–51Hz)。
- 设 ADC 触发定时器,使 **M 个整周期内恰好采 N 点(N 取 2 的幂)**。例:M=4 周期、N=1024 点 → 采样率 = 1024/(4×20ms)=**12.8kSPS**(对 4MSPS 的 ADC 毫无压力)。
- 整周期 → **FFT 无频谱泄漏、无需加窗**,各次谐波正好落在整数 bin:**基波在第 M 个 bin,第 h 次谐波在 h·M bin**(M=4 时 10 次谐波在 bin 40,Nyquist 在 bin 512,余量极大)。
- 多周期平均(M=4~10)提升信噪比。

### 3.2 前端互感器(隔离 + 低功耗)
- **电压**:ZMPT101B(2mA:2mA 电压互感器)+ 负载电阻 + 运放调理;250V 满量程靠原边限流电阻设定。
- **电流**:CT,**原边多匝缠绕**提高小电流灵敏度(题目明确允许),**匝数比在软件里可设**;负载电阻把副边电流转电压。
- 两路都要:**AC 耦合 + 抬到 1.65V 中点**(双极性 AC 塞进 0–3.3V 单极性 ADC)+ **抗混叠 RC**(截止设在采样率一半以下、谐波带宽以上,如几 kHz)。
- **善用 MSPM0 内置零漂运放(PGA 可到 32×)**做调理/增益,省外部器件和功耗;小电流时拉高 PGA 增益做**自动量程**保精度。

### 3.3 50mW 预算(显示是头号杀手)
- **禁用 TFT、禁用常亮亮 OLED**。用**反射式段码 LCD**(μA 级)或**反射式 STN 12864 无背光**(<1mA)或墨水屏。
- 电源用 **TPS62740 超低 Iq Buck**(Iq ~360nA)而非线性 LDO,轻载效率高。
- MCU 降频 + **突发计算后进 Sleep**(采一帧→算→显示→睡)。

## 5. 50mW 功耗预算分解(目标 ≤15mA @ 3.3V)

| 模块 | 估算电流@3.3V | 功率 | 省电措施 |
|---|---|---|---|
| MSPM0G3507(~40MHz,占空比运行) | ~4–5mA | ~15mW | 降频 + 突发算完进 Sleep |
| 2× 调理运放 | ~1–2mA | ~5mW | 用内置运放 / 低 Iq 外置 |
| 反射式段码/STN 显示(无背光) | <0.5mA | <2mW | 禁背光、反射式 |
| 偏置/基准/比较器 | ~1mA | ~3mW | 高阻分压 + 内置比较器 |
| Buck 自身(TPS62740) | <0.01mA | — | 超低 Iq |
| **合计** | **~8–10mA** | **~30–35mW** | **留 ~15mW 余量** |

> 注:**互感器原边能量来自市电/负载侧,不计入电池**;电池只供 MCU+运放+显示+偏置。预算可达标,但**显示选错就崩**——务必反射式。

## 6. 采样与算法

**时域(总量,鲁棒)**——在整数周期窗内:
- 真有效值:`Vrms = sqrt(Σ v[n]² / N)`,`Irms = sqrt(Σ i[n]² / N)`
- 有功功率:`P = Σ (v[n]·i[n]) / N` ← **靠双 ADC 同步采样**
- 视在功率:`S = Vrms · Irms`;无功:`Q = sqrt(S² − P²)`
- 功率因数:`PF = P / S`(含畸变;基波 cosφ 另由 FFT 基波相位算)

**频域(谐波/THD)**——`arm_rfft_fast_f32`(CMSIS-DSP)对整周期 N 点:
- 第 h 次谐波有效值 = |X[h·M]| × 标度(M=整周期数)
- 电流 THD `= sqrt(Σ_{h≥2} I_h²) / I_1`(至少取到 10 次)
- 频率:过零间隔 或 FFT 基波 bin

> 时域算总量 + 频域算谐波,两条腿都要;整周期保证两者都准。

## 7. 校准步骤(±1% 全靠这步,别省)

1. **偏置校准**:无输入时记录两路 ADC 中点,作零点基准。
2. **增益校准(多点)**:接标准表,在低/中/高三档加已知 V、I,拟合各通道增益系数;**分段线性**保全量程 ±1%。
3. **相位校准(最关键)**:接**纯阻性负载**(真实 PF=1),调相位补偿量 δ(对一路做分数延时/插值)使 **PF 读数=1.000**——消除 CT/PT 相移对 **P 和 PF** 的误差。**很多队就栽在这。**
4. **量程/匝数比**:设置 CT 匝数比参数;小电流用 PGA 提增益做自动量程。
5. **谐波验证**:用整流+电容或可控非线性负载,核对各次谐波与 THD ≤2%。

## 9. 调试与测试要点

- **标准参照**:商用功率分析仪/功率表(题目就是和商用 PA 比读数)。
- **抓波形**:UART 回传 v[n]、i[n] 到上位机,确认**同步、整周期、无削顶**。
- **负载谱**:纯阻(电阻/灯泡)、感性(电感/电机)、容性、**非线性(整流+电容、调光台灯)** 分别测 P/PF/THD。
- **功耗**:串直流电流表测整机电流,确认 <15mA;逐模块关断定位耗电大户。
- **小电流精度**:低端最难,靠多匝 CT + PGA 自动量程。

## 10. 风险与对策

| 风险 | 对策 |
|---|---|
| ⚡ **250V 强电安全** | 互感器隔离、加保险丝、爬电距离、**调试先用隔离变压器+低压**再上 250V |
| 50mW 超标 | 反射式显示、TPS62740、MCU 占空比、关无用外设 |
| P/PF 不达 ±1% | **相位校准**(第 7.3)+ 多点增益校准 |
| 谐波/THD 不准 | 整周期同步采样、整数 bin 取谐波、多周期平均 |
| 小电流误差大 | CT 原边多匝 + PGA 自动量程 + 分段校准 |
| 合规 | 分立前端 + MSPM0 做 DSP,**不用计量 AFE 芯片代算** |

## 12. 建议分工与里程碑

- **硬件(A)**:互感器前端 + 调理 + 电源(50mW)+ PCB;先做好可上电的最小前端。
- **软件(B,MSPM0)**:双 ADC 同步采样 → RMS/P/S/PF → FFT 谐波/THD → 显示;先在番茄派上跑通同步采样 + FFT。
- **系统/测试(C)**:校准(增益/相位/量程)+ 标准表对比 + 功耗实测 + 报告。
- **里程碑**:① 同步采样 + 纯阻负载 P/PF 跑通 → ② 加谐波/THD → ③ 全量程多点校准达 ±1% → ④ 功耗压到 <50mW → ⑤ 计时整机 + 报告。
