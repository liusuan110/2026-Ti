# AD9959 DDS 信号源资料

> 电赛信号类最常用的 DDS（直接数字频率合成）信号源芯片。
> 4 通道、500 MSPS、每通道独立频率/相位/幅度，硬件级 ASK/FSK/PSK 调制 + 线性扫频。
> 几乎所有"自制信号源 / 超外差本振 / 扫频源"的开源方案都用它。

---

## 一句话规格

| 项目 | 参数 |
|---|---|
| 通道数 | **4 路独立** DDS（共用一个系统时钟，天然同步） |
| 最高系统时钟 | **500 MSPS** |
| 频率分辨率 | 500 MHz / 2³² ≈ **0.116 Hz** |
| 频率调谐字 | 32 bit（FTW） |
| 相位分辨率 | 14 bit（≈ 0.022°），可做 I/Q 正交 |
| 幅度分辨率 | 10 bit（每通道独立可调，可做 ASK） |
| DAC | 每通道 10 bit，互补电流输出 |
| 实际可用输出 | 单通道约 ≤ 160–200 MHz（受重构滤波器限制，工程常用几十 MHz） |
| 调制 | 硬件级 2/4/8/16 电平 **FSK / PSK / ASK** + 线性扫频（chirp） |
| 接口 | SPI 兼容串口（SCLK 最高 ~200 MHz）+ 4 根 Profile 引脚 |
| 供电 | 1.8 V 内核 + 3.3 V I/O，56-LFCSP 封装 |

## 在电赛里的定位（为什么几乎人手一片）

信号类题目里，AD9959 通常承担三个角色：

1. **信号源** —— 产生标准 AM/FM/ASK/FSK/PSK 测试信号（自测/标定用），或作为题目要求的"被测/发射信号"。
2. **本振（LO）** —— 超外差接收机里产生本振，配模拟乘法器（如 AD835）下变频到低中频，再交给 ADC/单片机处理。例：2023 同轴电缆检测（杭电）用 `AD9959 + 2×AD835 + ADS131A04` 的超外差链路。
3. **扫频源** —— 线性扫频做幅频特性测量 / 网络分析 / 阻抗测量。

> 对照你仓库里已有的方向：FPGA 那套（hewzhew / 华科）负责**解调与识别（接收端）**，AD9959 负责**信号生成（发射/激励端）**——两头正好配成一套完整的收发/测量系统。
