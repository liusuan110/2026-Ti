# AD9959：从数字参数到模拟波形

AD9959 在这份备赛资料里承担输出端的角色：主控告诉它频率、相位和幅度，它再用内部时钟与 DAC 持续生成模拟信号。学习采样时关注“输入里有什么”，学习 DDS 时关注“怎样把识别出的参数变成输出”。

第一次接触时，先用本地培训工程观察现成行为，再回到寄存器说明，比较容易把软件设置与示波器上的波形对应起来。

## 先运行哪份工程

[番茄派 MSPM0G3507 培训工程](番茄派例程-MSPM0G3507_AD9959-学长培训/_导读-本地说明.md) 保存了 GPIO 串行控制 AD9959 的 CCS 工程。主入口是 `MSPM0G3507_AD9959DDSCtrl_Demo.c`，演示安排在 `User/UserTask.c`：

- 开始 5 s，四通道均为 1 kHz，相位依次为 0°、90°、180°、270°。
- 随后 CH0 保持点频，CH1 线性扫频，CH2 对数扫频，CH3 扫幅。

先看点频与相位，再看扫描，可以依次理解三个控制量。导入位置、接线入口和对应函数见[本地导读](番茄派例程-MSPM0G3507_AD9959-学长培训/_导读-本地说明.md)。

## 三个参数怎样控制输出

| 参数 | 在输出端看到什么 | 软件里对应什么 |
| --- | --- | --- |
| 频率 | 一个周期有多长 | 32 位频率控制字 FTW |
| 相位 | 同频信号之间的位置关系 | 14 位相位字 POW |
| 幅度 | 输出波形的跨度 | 10 位幅度字 ASF |

频率字的换算依赖 DDS 系统时钟：`FTW = round(f_out × 2^32 / f_sys)`。培训工程使用 25 MHz 参考、PLL 倍频到 500 MHz；[F题后续工程](https://github.com/liusuan110/ti-last) 则采用 25 MHz PLL 旁路配置。比较驱动时，先找到系统时钟设置，再看频率字计算。

模拟输出还经过滤波、负载与放大链路。芯片参数决定数字设置的分辨率，示波器上的实际电压跨度则要沿输出电路测量和标定。
