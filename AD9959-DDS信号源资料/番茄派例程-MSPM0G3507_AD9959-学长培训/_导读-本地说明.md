# 番茄派 AD9959 培训工程：先看输出，再读驱动

这份工程用 MSPM0G3507 的 GPIO 串行总线控制 AD9959，来自学长培训资料。它把点频、相位差和扫描放在同一个演示里，适合用示波器认识 DDS 的几个基本控制量。

## 代码在哪里

在 CCS 中将当前目录作为现有工程导入。先打开同目录 SysConfig，查看时钟和 `GPIO_DDS` 引脚，再沿下面的顺序阅读：

| 入口 | 看什么 |
| --- | --- |
| [主程序](MSPM0G3507_AD9959DDSCtrl_Demo.c) | 初始化与调度 |
| [User/UserTask.c](User/UserTask.c) | 演示的时间顺序与各通道设置 |
| [User/AD9959.h](User/AD9959.h) | 引脚约定、时钟与驱动接口 |
| [User/AD9959.c](User/AD9959.c) | 寄存器写入与底层总线 |
| [学长原说明](README.md) | 原工程介绍与硬件使用记录 |

主控采用外部 40 MHz 时钟生成 80 MHz；AD9959 则从 25 MHz 参考经 PLL 得到 500 MHz 系统时钟。先对应自己的板卡、模块供电与时钟，再观察输出。

## 上电后按什么顺序观察

程序开始的 5 s，四路都设为 1 kHz，相位依次为 0°、90°、180°、270°。先观察单路频率，再用双通道示波器比较相位差。

随后 CH0 保持点频，CH1 线性扫频，CH2 对数扫频，CH3 扫幅。对照 `UserTask.c` 的调用，可以把波形变化与设置频率、相位和幅度的函数一一对应。

接线时，把 SysConfig 的 `GPIO_DDS` 与 `AD9959.h` 对照。原说明记录了模块上电顺序和低频负载问题；输出经隔直与负载后，按实际频段选择缓冲和放大电路，电路讨论见[硬件接口文章](../02-硬件接口与电路设计.md)。

## 从演示走向自己的题目

先保留一路点频作为基准，只改一个控制量观察结果；再把固定参数换成算法给出的频率或相位。常用接口包括 `AD9959_setFreq/setAmp/setPhase`，以及 DDS 层的点频和扫描封装，具体声明见驱动头文件。

把它用作识别算法的测试信号源时，从已知参数的点频开始，再逐步加入扫描或调制。相关寄存器说明见[03 驱动开发](../03-寄存器映射与驱动开发.md)，应用路线见[04 调制与电赛应用](../04-电赛应用与调制实现.md)。
