# 导读 · 番茄派 MSPM0G3507 驱动 AD9959 例程(学长培训）

> **出处**：学长培训资料 `培训资料/AD9959控制例程.zip`，纳入仓库作信号源参考。
> **已剥离 `Debug/` 编译产物**（508KB，CCS 重新构建即可生成）。工程详情见同目录 `README.md`（学长原文）。

## 这是什么

番茄派(MSPM0G3507)用 **GPIO 软件模拟 SPI** 控制 AD9959 的**完整 CCS 工程**，是本仓库 `AD9959-DDS信号源资料/` 文档的**配套实跑代码**，应已在番茄派上验证。

- 主频 80MHz（40MHz 晶振倍频）；AD9959 PLL 25MHz→500MHz。
- 引脚映射在 `User/AD9959.h` 顶部注释 + `.syscfg`（SysConfig 的 `GPIO_DDS` 组，可改）。

## 关键 API（在 `User/AD9959.c`，对照本资料 `03/04`）

| 需求 | 函数 |
|---|---|
| 点频/控幅/控相 | `AD9959_setFreq / setAmp / setPhase`（或 `DDS_singleTone`） |
| **2~16 电平 FSK** | `AD9959_modulationInit` + `AD9959_setFSK` |
| **2~16 电平 ASK** | `…setASK` |
| **2~16 电平 PSK** | `…setPSK` |
| 线性/对数扫频·扫幅·扫相 | `AD9959_setFreqSweep / setAmpSweep / setPhaseSweep`、`DDS_sweep` |

## 对照 2023-D 题(调制识别）—— 拿它当"标准信号源"

要自测识别算法时，用这份代码产生**已知参数**信号去喂接收端：
- **2ASK / 2FSK / 2PSK**：`modulationInit(ch, FSK/ASK/PSK, …, LEVEL_MOD_2)` + 对应 `setXSK`，基带码流(6/8/10kbps)由定时器驱动 Profile 引脚。
- **CW**：`setFreq` 单频 2MHz。
- **AM/FM**：AD9959 原生不擅长连续调制，见 `04-电赛应用与调制实现.md`（建议外接 AD835 模拟相乘 / 软改寄存器）。

## 和另一份驱动的关系

- 本份 = **MSPM0（番茄派原生，TI SDK）** → 你主用这份。
- `开源参考-veis-lzf-DDS-AD9959/` = **STM32F4（寄存器级 + Altium 硬件）** → 移植/对照/看硬件。
- 两份寄存器逻辑一致，差别只在底层 GPIO/SPI。

## 三个坑(学长 README 已强调，重点记）

1. **AD9959 模块要比单片机先上电**，否则 PLL 时钟错、输出频率不对。
2. 输出有**隔直电容**，低频时驱动不了低阻负载——需后级运放缓冲（参考同级目录 `参考-NE5532缓冲放大板.pdf` 和 `02` 文档）。
3. 软件模拟 SPI，换引脚要在 SysConfig 里把 `GPIO_DDS` 组改成和 `AD9959.h` 一致。
