# 02 · 硬件接口与电路设计

## 1. 引脚分组（按功能记）

| 组 | 引脚 | 作用 |
|---|---|---|
| **时钟** | REF_CLK / REF_CLK_B | 参考时钟输入（晶振或外部时钟），经内部 PLL 倍频成系统时钟 f_S |
| **串口** | SCLK、SDIO_0~3、CS（CSB）、IO_UPDATE | SPI 写寄存器；IO_UPDATE 上升沿把缓冲值"提交"为生效值 |
| **控制** | RESET、PWR_DWN、SYNC_CLK、PDClk | 复位、掉电、同步时钟输出 |
| **调制** | **P0、P1、P2、P3** | Profile 引脚：硬件实时切换调制电平 / 扫频上下方向 |
| **输出** | OUT0~3 / OUT0_B~3_B | 4 路互补电流输出（DAC） |
| **基准** | DAC_RSET | 外接 R_SET 电阻设定 DAC 满量程电流 |

> SDIO 有 0~3 共 4 根，是为了支持 2 线 / 3 线 / 4 线串口模式。最简单用 **3 线模式**（SDIO_0 做数据输入），其余可空/复用。

---

## 2. 时钟与 PLL

- 最省事方案：**外接 25 MHz 晶振 → 内部 PLL ×20 → f_S = 500 MHz**。
- PLL 倍频系数在功能寄存器 FR1 里设（4×…20×）。
- **系统时钟 > 255 MHz 时，必须把 FR1 里的 "VCO gain control" 位置 1**，否则 PLL 锁不住 → 无输出 / 输出乱跳。这是最常见的"配了寄存器却没波形"原因。
- 也可外部直接灌 500 MHz 时钟（这时关 PLL），信号纯净度更好但需要外部时钟源。

---

## 3. 输出调理（最关键、最容易翻车的一段）

DDS 出来的是**阶梯状电流**，含有镜像/杂散，**必须**经过两级处理才能用：

```
OUTx / OUTx_B  →  ① 电流转电压（负载电阻/变压器）  →  ② 重构低通滤波(LPF)  →  ③ 运放缓冲/放大  →  输出(50Ω)
```

### ① 电流→电压
- 互补电流输出，常接 **50Ω 到地**（或差分变压器，如 ADT1-1WT），把电流转成电压。
- 满量程电流约 10 mA，单端 50Ω 上得到约 0.5 Vpp 量级 → 需要后级放大。

### ② 重构低通滤波（reconstruction filter）
- 必须有！滤掉 DAC 的镜像分量（f_S − f_out 等）。
- 典型 **7 阶椭圆/巴特沃斯 LPF**，截止频率取你最高输出频率以上、f_S/2 以下（如最高用 40 MHz，截止取约 50–70 MHz）。
- 不同最高频率要重算滤波器；很多模块板载固定截止，注意它的可用带宽。

### ③ 运放缓冲 / 放大
- 用**高速运放**驱动 50Ω 负载并放大到所需幅度（如 1~2 Vpp）。
- 常见型号：**AD8009 / THS3201 / AD811 / OPA690** 等高速电流反馈运放（带宽几百 MHz）。
- 若做超外差本振，本振口对幅度/纯度要求高，运放选型和滤波要更讲究。

> 这一段是"能不能用"的分水岭：很多人寄存器全对、示波器却只有几十 mV 的丑波形，就是卡在没做好滤波 + 放大。

## 4. 接口电平与连线（接 STM32/GD32/FPGA）

- I/O 是 **3.3 V**，可直连 STM32/GD32/大多数 FPGA bank，不用电平转换。
- 最少连线（3 线 SPI 模式）：`SCLK / SDIO_0 / CS / IO_UPDATE / RESET` + 调制用的 `P0(~P3)`。
- **P0–P3 一定要接到 MCU/FPGA 的 GPIO**（哪怕暂时只用 P0），否则没法做硬件 FSK/PSK/ASK。
- SCLK 别拉太高，先用几 MHz 调通再提速；走线短、地完整。

## 5. 模块 / 开发板选型建议

- **直接买现成 AD9959 模块**（淘宝/立创都有，几十元级），别自己画第一版 PCB。
- 选模块看三点：
  1. **板载晶振频率**（多为 25 MHz，确认 PLL 后系统时钟）；
  2. **输出有没有运放/滤波**（有的模块直接出 DAC 裸输出，需要你自己加调理）；
  3. **P0–P3 有没有引出**（做调制必须要）。
- 想要原理图参考：**GitHub `veis-lzf/DDS-AD9959` 有完整 Altium 工程（原理图 + PCB + 库）**，照着看接口和输出调理怎么做（见 `05`）。

## 6. 调试自检清单

- [ ] PLL 锁定？（>255MHz 系统时钟置 VCO gain 位）
- [ ] 写完寄存器**脉冲了 IO_UPDATE**？
- [ ] CSR 里**通道使能位**对应到你要输出的通道？
- [ ] R_SET 电阻装了、阻值对？（决定输出幅度）
- [ ] 输出有没有**重构滤波 + 运放**？裸 DAC 输出不能直接上示波器判好坏。
- [ ] 频率算错？复核 `FTW = round(f_out × 2³² / f_S)`，f_S 是不是 PLL 后的真实值。
