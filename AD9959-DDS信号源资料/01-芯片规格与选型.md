# 01 · AD9959 芯片规格与选型

## 1. 它是什么

AD9959 是 ADI（Analog Devices）的**4 通道直接数字频率合成器（DDS）**。
内部每个通道是一套独立的 `相位累加器 → 相位/幅度映射 → 10-bit DAC`，4 个通道共用同一个系统时钟，所以**4 路输出天然同步**，相位关系可精确设定（做 I/Q 正交、多音、阵列移相都靠这个）。

核心卖点：**频率、相位、幅度三者每通道独立、且都能被"硬件 Profile 引脚"实时切换** → 不靠 CPU 发命令就能产生干净的 FSK/PSK/ASK 和扫频。

---

## 2. 关键参数

| 参数 | 数值 | 说明 |
|---|---|---|
| 系统时钟 f_S | 最高 **500 MHz** | 可外部直接给，或用内部 PLL（×4…×20）从低频晶振倍频 |
| 通道数 | 4，独立 | 共用 f_S |
| 频率调谐字 FTW | 32 bit | f_out = FTW × f_S / 2³² |
| 频率分辨率 | ≈ **0.116 Hz** @500MHz | = f_S / 2³² |
| 相位偏移字 POW | 14 bit | 分辨率 ≈ 360°/2¹⁴ ≈ 0.022° |
| 幅度控制 | 10 bit/通道 | 可做幅度调制 / 各路幅度配平 |
| DAC | 10 bit，互补电流输出 | 满量程电流由 R_SET 设定（典型约 10 mA） |
| SFDR | 窄带典型 ~80 dBc | 输出质量足够做信号源 |
| 最高模拟输出 | 理论 Nyquist 250 MHz | 工程上受重构滤波器限制，可用约 ≤160–200 MHz；常用几十 MHz |
| 串口 SCLK | 最高约 200 MHz | SPI 兼容，2/3/4 线可选 |
| Profile 引脚 | P0–P3（4 根） | 硬件切换调制电平 / 扫频方向 |
| 供电 | 1.8 V 内核 + 3.3 V I/O | |
| 封装 | 56-lead LFCSP（QFN） | 手焊困难，建议买现成模块 |

## 3. 它能干什么（信号类视角）

- **任意频率正弦** 0.1 Hz 步进，0 → ~160 MHz。
- **4 路同步** —— 设相位差 90° 得到正交 I/Q；多路不同频得到多音信号。
- **线性扫频（chirp）** —— 频率按设定斜率自动上/下扫，做幅频特性、扫频测量。
- **硬件调制** —— 2/4/8/16 电平的 FSK / PSK / ASK，由 P0–P3 引脚实时切换，无 CPU 延迟、切换干净。
- **幅度可调** —— 每路 10 bit 幅度，做 ASK 或自动电平控制 / 配平。

> ⚠️ 注意：AD9959 **本身只产生 FSK/PSK/ASK 这类"键控/数字调制"和扫频**。
> **模拟 AM / FM**（连续调制度 ma、调频指数 mf）严格说要靠"实时改写频率/幅度寄存器"或外部电路来近似，见 `04`。

## 4. 选型对比（同门 DDS 怎么选）

| 芯片 | 通道 | 时钟 | DAC | 特点 | 适合 |
|---|---|---|---|---|---|
| **AD9959** | **4** | 500 MSPS | 10 bit | 多通道 + 硬件 FSK/PSK/ASK + 扫频 | **信号类首选**：本振、I/Q、多音、键控调制 |
| AD9954 | 1 | 400 MSPS | 14 bit | 单通道、14 位 DAC、扫频 | 单路高质量正弦 / 扫频 |
| AD9910 | 1 | 1 GSPS | 14 bit | 高频、RAM 调制、性能强但贵且难 | 高频/高性能需求，门槛高 |
| AD9854 | 1（I/Q） | 300 MSPS | 12 bit | 自带正交 I/Q 输出、老牌 | 需要正交且不想多芯片 |
| AD9851/9850 | 1 | 180/125 MSPS | 10 bit | 便宜、模块满街、入门 | 低频简单正弦源、教学 |

**结论**：信号类要"多路 + 调制 + 本振"，AD9959 几乎是唯一兼顾的；只要单路正弦/扫频，AD9851 模块更便宜好上手。

## 5. 局限 / 坑（先知道再用）

- **手焊几乎不可能**（QFN56 + 多电源 + 时钟），**直接买模块**，别自己画第一版。
- **输出是互补电流、幅度小**，必须加**重构低通滤波 + 运放/变压器**才能驱动 50Ω 和示波器（见 `02`）。
- **PLL 倍频到 >255MHz 系统时钟时要置 VCO gain 位**，忘了会无输出或不稳。
- **每次写完寄存器要脉冲 IO_UPDATE** 才生效，新手最常忘。
- **模拟 AM/FM 不是它的强项**（它是数字键控 DDS），连续调制要技巧，见 `04`。
