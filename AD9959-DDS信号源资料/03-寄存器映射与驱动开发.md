# 03 · 寄存器映射与驱动开发

> 驱动跟 MCU 无关——STM32 / GD32 / FPGA 用的是**同一套寄存器**，区别只是底层 SPI 怎么发。
> ⚠️ 下面地址可靠，**具体位域以 AD9959 数据手册（Register Map 章节）为准**，不同 Rev 略有差异。

---

## 1. 串口写时序

每次访问 = **1 字节指令 + N 字节数据**：

```
指令字节:  [bit7 = R/W (0=写)] [bit6..0 = 寄存器地址]
数据字节:  该寄存器的内容（MSB first，字节数见下表）
```

写完一批寄存器后，**拉一个 IO_UPDATE 上升沿**，缓冲值才整体生效。

---

## 2. 主要寄存器一览

| 地址 | 名称 | 字节 | 作用 |
|---|---|---|---|
| `0x00` | **CSR** Channel Select | 1 | 选哪几路通道生效、串口线数（2/3/4 线）、MSB/LSB |
| `0x01` | **FR1** Function Reg 1 | 3 | **PLL 倍频系数**、VCO gain、调制电平数、ramp 设置 |
| `0x02` | FR2 Function Reg 2 | 2 | 多通道同步、扫频无停留等 |
| `0x03` | **CFR** Channel Function | 3 | **调制类型选择(AFP)**、扫频使能、DAC 满量程 |
| `0x04` | **CFTW0** 频率调谐字 | 4 | 32-bit FTW（决定输出频率） |
| `0x05` | **CPOW0** 相位偏移字 | 2 | 14-bit 相位 |
| `0x06` | **ACR** 幅度控制 | 3 | 10-bit 幅度 + 幅度乘法器使能位 |
| `0x07` | LSRR 线性扫频速率 | 2 | 扫频步进时间间隔 |
| `0x08` | RDW 上升 Delta 字 | 4 | 扫频每步增量（上行） |
| `0x09` | FDW 下降 Delta 字 | 4 | 扫频每步增量（下行） |
| `0x0A`–`0x0F` | CW1–CW15 通道字 | 4 | 调制用的预置频率/相位/幅度档位（配合 P0–P3） |

> **AFP** = Amplitude / Frequency / Phase 调制选择位（在 CFR 里）：决定 P0–P3 切换的是幅度（ASK）、频率（FSK）还是相位（PSK）。

---

## 3. 三个核心计算公式

设系统时钟 **f_S**（PLL 后的真实值，如 500 MHz）：

**频率**（写入 CFTW0）：
```
FTW = round( f_out × 2³² / f_S )        // 32-bit
例: f_out=10MHz, f_S=500MHz → FTW = round(10e6 × 2³² / 500e6) = 0x051EB851
```

**相位**（写入 CPOW0）：
```
POW = round( phase_deg / 360 × 2¹⁴ )    // 14-bit
例: 90° → POW = round(90/360 × 16384) = 4096 = 0x1000
```

**幅度**（写入 ACR，需置幅度乘法器使能位）：
```
ASF = round( A / A_full × 1023 )        // 10-bit
满幅就给 0x3FF；做 ASK 在两档幅度间切换
```

## 4. 初始化流程（伪代码）

```c
AD9959_Reset();                       // 复位引脚给一个高脉冲

// 1) CSR: 选通道 + 串口模式(3线) + MSB first
write_reg(0x00, {0xF0 | mode_bits});  // 0xF0 = 4 路全使能(bit7..4)

// 2) FR1: PLL ×20, >255MHz 系统时钟置 VCO gain 位, charge pump
write_reg(0x01, {0xD0, 0x00, 0x00});  // 示例值，依手册算

// 3) CFR: 关调制(单频)/或选 AFP, DAC 满量程
write_reg(0x03, {0x00, 0x03, 0x02});  // 示例

// 4) 频率
uint32 ftw = (uint64)f_out * 0x100000000ULL / f_S;
write_reg(0x04, ftw_bytes_MSBfirst);

// 5) 相位
write_reg(0x05, pow_bytes);

// 6) 幅度(置使能位 + 10bit)
write_reg(0x06, acr_bytes);

// 7) 提交
IO_UPDATE_pulse();                    // 关键！不脉冲不生效
```

> 想换某一路通道：先写 CSR 选中该通道，再写它的 CFTW0/CPOW0/ACR，最后 IO_UPDATE。

## 5. 硬件调制配置（FSK / PSK / ASK）

思路：**把若干"档位"预置进 CW 寄存器，用 P0–P3 引脚实时切换**。基带数据流直接驱动 P 引脚，切换干净、无 CPU 延迟。

### 2 电平 FSK（最常用）
1. FR1 设调制电平 = 2 级；
2. CFR 的 AFP 选 **频率调制**；
3. CFTW0 (= CW0) 写 f0，CW1（0x0A）写 f1；
4. **P0 = 0 → 输出 f0；P0 = 1 → 输出 f1**。基带比特接 P0。

### 2 电平 PSK
- AFP 选**相位调制**；CW0/CW1 存两个相位（如 0° / 180°）；P0 切换 → 2PSK。

### 2 电平 ASK
- AFP 选**幅度调制**；CW0/CW1 存两个幅度；P0 切换 → 2ASK（OOK 就是一档为 0）。

### 4 / 8 / 16 电平
- 用更多 P 引脚（P0–P3）+ 更多 CW 寄存器，可做 4FSK / QPSK 等。

---

## 6. 线性扫频（chirp / 扫频源）

1. CFR 置**线性扫频使能**位；
2. CFTW0 = 起始频率，CW1 = 终止频率；
3. RDW(0x08) = 上行每步增量，FDW(0x09) = 下行每步增量，LSRR(0x07) = 每步停留时间；
4. **P 引脚控制扫频方向**（拉高向上扫、拉低向下扫）。

得到的就是频率随时间线性变化的扫频信号，用于幅频特性 / 网络分析 / 阻抗测量。

---

## 7. 常见 Bug 速查

| 现象 | 多半是 |
|---|---|
| 完全无输出 | 没脉冲 IO_UPDATE / PLL 没锁（VCO gain 位）/ CSR 没使能该通道 |
| 频率不对（差一个倍数） | 公式里 f_S 用错（用了晶振频率而非 PLL 后的值） |
| 输出很小很丑 | 没加重构滤波 + 运放（见 `02`），裸 DAC 输出 |
| 调制切换有毛刺 | 用串口改寄存器做调制（慢）而非 P 引脚硬件切换 |
| 多路相位对不齐 | 没做通道同步（FR2）/ 没在同一 IO_UPDATE 提交 |
