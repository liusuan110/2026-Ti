# 04 · 电赛应用与调制实现

> 把 AD9959 的能力对应到信号类题目的真实需求，重点是**怎么用它生成 AM/FM/ASK/FSK/PSK**，并对照 2023-D 题（调制信号识别）的参数。

---

## 1. 三种典型用法

### A. 信号源（产生被测/标准信号）
- 题目要"产生某种调制信号"或你要自测解调算法时，用 AD9959 当信号发生器。
- 4 路独立：一路出载波、一路出本振、一路出参考……灵活分配。

### B. 超外差本振（接收机下变频）
- 经典链路：`天线/输入 → LNA → 混频器(AD831/AD835/ADL5801) ← AD9959本振 → 中频滤波 → ADC → MCU/FPGA`。
- AD9959 提供**可调本振**，把高频信号搬到固定低中频，降低对 ADC 采样率的要求。
- 范例：**2023 同轴电缆检测（杭电国一）** = `AD9959(DDS扫频/本振) + 2×AD835(模拟乘法器超外差) + ADS131A04(24-bit ADC)`，下变频到约 2.5 kHz 中频再采样。见 `05`。

### C. 扫频源（幅频特性 / 网络分析）
- 线性扫频模式，扫频测幅频响应、谐振点、阻抗。

---

## 2. 各调制怎么生成（核心）

AD9959 是**数字键控 DDS**，对"数字调制"（ASK/FSK/PSK）是原生支持；对"模拟连续调制"（AM/FM）要用技巧。

### ✅ 2FSK / 2PSK / 2ASK —— 原生硬件支持（最干净）
- 见 `03 §5`：预置 CW 档位 + P0 引脚实时切换，基带比特流接 P0。
- 切换由硬件完成、无 CPU 延迟，码元边沿干净——这是 AD9959 最适合做的事。
- 多电平（4FSK/QPSK/16QAM 近似）用 P0–P3 + 更多 CW。

### ⚠️ 模拟 AM（调幅，连续调制度 ma）
AD9959 没有"模拟幅度调制输入脚"，两条路：
1. **软件实时改写幅度寄存器 ACR**：MCU/FPGA 按调制波形 m(t) 高速更新 ASF = A·(1 + ma·m(t))。受串口速率限制，调制频率不能太高。
2. **外部模拟相乘**：AD9959 出纯载波，外接模拟乘法器（AD835）× 基带 → 标准 AM。**推荐**，波形质量好、ma 连续可调。
   - 标准 AM：`s(t) = A[1 + ma·cos(2πf_m t)]·cos(2πf_c t)`，ma = 调制度。

### ⚠️ 模拟 FM（调频，调频指数 mf）
1. **软件实时改写频率寄存器 CFTW0**：按 f(t) = f_c + Δf·m(t) 高速更新 FTW。简单但更新率有限。
2. **线性扫频近似**：用扫频功能产生三角/锯齿调频。
3. 严格正弦 FM 一般靠方法 1 提高更新率，或用支持 RAM 调制的更高端 DDS（AD9910）。
   - mf = Δf / f_m（调频指数 = 最大频偏 / 调制频率）。

> **小结**：键控类（FSK/PSK/ASK）放心用 AD9959 硬件；模拟 AM/FM 优先"AD9959 出载波 + 外部模拟电路"，或接受软件改寄存器的更新率上限。

## 3. 对照 2023-D 题（调制信号识别）参数

2023-D 要识别 6 类：**CW / AM / FM / 2ASK / 2PSK / 2FSK**，并测调制参数。如果你要**自己产生这些信号**做调试/标定，AD9959 的配置如下：

| 题目信号 | 题目参数 | AD9959 怎么产生 |
|---|---|---|
| CW（载波） | f_c = 2 MHz | 单频，CFTW0 = 2 MHz，不调制 |
| AM | 0.3 < ma < 1，f_m = 1–5 kHz | 出 2MHz 载波 + 外部 AD835 × 基带（推荐），或软改 ACR |
| FM | 1 ≤ mf ≤ 5，F = 1–5 kHz | 软件高速改 CFTW0 按正弦扫频，Δf = mf·F |
| 2ASK | Rc = 6/8/10 kbps | AFP=幅度，CW0/CW1=两档幅度，P0 接码流 |
| 2PSK | Rc = 6/8/10 kbps | AFP=相位，CW0/CW1=0°/180°，P0 接码流 |
| 2FSK | 2 ≤ h ≤ 5，Rc=6/8/10kbps | AFP=频率，CW0/CW1=f0/f1（频差=h·Rc），P0 接码流 |

> 这样你就有了一台"已知参数的标准信号源"，可以拿来**验证你（或学长 FPGA）的识别算法**——发已知 ma/mf/h/Rc，看识别结果对不对，误差是否满足题目（ma≤0.1、mf≤0.3、F≤50Hz 等）。

载波 2 MHz 远低于 AD9959 上限，频率/相位精度绰绰有余；基带码流（6/8/10 kbps）由 MCU/FPGA 的定时器产生接到 P0 即可。

## 4. 一套"发射端"参考架构（配合你仓库的 FPGA 接收端）

```
[MCU/FPGA 基带发生]
   ├─ 码流(6/8/10kbps) ─→ P0  ┐
   └─ 寄存器配置(SPI) ───────→ │  AD9959  ─→ 重构LPF ─→ 运放 ─→ 已知调制信号
                               ┘                                    │
                                                                    ▼
                                              [学长 FPGA / MSPM0 接收识别]  ← 你仓库已有
```

- **发射端**（本资料 + AD9959）产生已知信号；
- **接收端**（仓库里 hewzhew / 华科 FPGA、或 MSPM0 方案）识别并测参数；
- 合起来 = 一套可自测闭环的完整系统，备赛演示和调参都靠它。

---

## 5. 实用建议

- 先用 AD9959 把 **CW / 2ASK / 2FSK / 2PSK** 跑通（硬件原生，最快出结果）。
- **AM/FM** 留到后面，优先"载波 + 外部 AD835/模拟电路"方案，别硬刚软件改寄存器的更新率。
- 基带码元速率、频差、调制度都做成**可调参数**，方便扫不同工况测算法鲁棒性。
- 本振用途时，重点保证**本振口幅度稳定、杂散低**（滤波 + 运放选型见 `02`）。
