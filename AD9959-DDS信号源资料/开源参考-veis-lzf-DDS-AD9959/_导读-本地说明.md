## 里面有什么

| 路径 | 内容 | 怎么用 |
|---|---|---|
| `Software/ad9959.c` `.h` | **STM32F4 寄存器级驱动**（366 行） | 直接移植：`Write_frequence / Write_Amplitude / Write_Phase / IO_Update` |
| `Hardware/*.SchDoc` `.PcbDoc` `.PrjPcb` | **完整 Altium 工程**（MCU / IO / LP Filter / POWER 原理图 + PCB + 库） | 用 Altium 打开；没装就看下面的 PDF |
| `Hardware/Assembly Drawing/*.pdf` | 原理图 / PCB 的 PDF 导出 | **不装 Altium 也能看**电路 |
| `Hardware/Datasheet/AD9959.pdf` | **AD9959 官方数据手册** | 核对寄存器位域（配合本资料 `03`） |
| `Hardware/Datasheet/ETC1-1-13.pdf` `TC1-1T.pdf` | 输出变压器手册 | 输出调理参考（配合 `02`） |
| `Hardware/Reference Document/*.pdf` | ADI 官方参考原理图 | 抄输出/时钟/电源设计 |
| `Hardware/Picture/*.png` | 3D 渲染 / 装配图 | 看实物形态 |

## 和本资料文件夹怎么配合

- 看 `03-寄存器映射与驱动开发.md` 学原理 → 对照 `Software/ad9959.c` 看真实实现（地址定义完全一致：CSR=0x00 … FDW=0x09）。
- 看 `02-硬件接口与电路设计.md` 的"输出调理"章 → 对照 `Hardware/03-LP Filter.SchDoc`（重构低通滤波）和参考原理图。
- 寄存器位域拿不准 → 直接查 `Hardware/Datasheet/AD9959.pdf`。

## 注意

- `.SchDoc / .PcbDoc / .SchLib` 是 Altium 二进制格式，需 Altium Designer 打开；只看电路用 `Assembly Drawing/` 里的 PDF。
- 驱动基于 STM32F4 的 `PDout()` 位带操作；移植到 MSPM0/GD32 时把引脚宏和 SPI 底层换掉即可，寄存器写入逻辑通用。
