# 从一个任务找到对应资产

这份索引按“采集与输出、识别与解调、测量与系统设计”组织资料。每条路线先说明要学什么，再给出工程入口；需要直接查平台与进度时，跳到[工程速查](#工程速查)。

## 从采集走到输出

先把采样节拍建立起来。[15_adc_dma_time_trigger](../MSPM0例程-双ADC同步采样与FFT/15_adc_dma_time_trigger/README.md) 展示定时触发的采集方式，适合观察定时器、ADC 和 DMA 怎样配合。再对照 [14_adc_dma_2ch](../MSPM0例程-双ADC同步采样与FFT/14_adc_dma_2ch/README.md)，看两路数据如何进入缓冲区：这个例程用一个 ADC 依次转换两个通道，做幅相测量时，要把通道间的采样时间差一起考虑。

拿到时域数据后，进入 [12_FFT](../MSPM0例程-双ADC同步采样与FFT/12_FFT/README.md)，把采样点、频率分辨率和频谱峰值对应起来。三份例程的整体说明在 [MSPM0 总览](../MSPM0例程-双ADC同步采样与FFT/README.md)。

输出端从 [AD9959 资料](../AD9959-DDS信号源资料/README.md) 开始，依次阅读硬件接口、寄存器和驱动。频率字、相位字和幅度字在这里是具体的控制手段；到了 H题，它们用于把识别结果重新合成为输出信号。[番茄派培训例程](../AD9959-DDS信号源资料/番茄派例程-MSPM0G3507_AD9959-学长培训/_导读-本地说明.md) 提供了连接驱动与开发板的入口。

### 用 H题把模块串起来

H题留下了两套 MSPM0 工程。[H_SignalSep](../2023-H题-信号分离-番茄派工程/代码/README.md) 按采集、分析、重建和控制组织代码，适合阅读模块之间的关系，也保存了编译与离板算法测试记录。

[SignalSeparator_v2](../2023-H题-信号分离-番茄派工程/代码/SignalSeparator_v2/README.md) 保存了后续版本，[2026-07-07 状态](../2023-H题-信号分离-番茄派工程/当前状态-2026-07-07.md) 记录了编译、接线和调试进度。v2 的 AD9959 接线为 PA8 / PA9 / PB3 / PB2 / PA7，主输入为 PA27。继续某一版本时，从该版本自己的说明展开。

需要比较另一种平台实现时，阅读 [STM32 开源参考导读](../2023-H题-信号分离-STM32开源参考/导读.md)与[原工程说明](../2023-H题-信号分离-STM32开源参考/2023-H-SHR-sky/README.md)。接线和整机联调材料还包括[番茄派-AD9959 指南](../2023-H题-信号分离-番茄派工程/番茄派-AD9959接线与最小联调指南.md)、[联调清单](../2023-H题-信号分离-番茄派工程/上板联调清单.md)和[串口屏资料](../2023-H题-信号分离-番茄派工程/串口屏/)。

## 从信号特征走到识别

[2023 D完整学习包](../2023-D题-完整学习包.md) 适合先建立问题框架：哪些特征能区分信号，处理链路如何提取这些特征，识别与解调分别需要什么结果。

接着读 [FPGA 本地导读](../2023-D题-FPGA信号识别-学长参考/导读.md)，再进入[工程 README](../2023-D题-FPGA信号识别-学长参考/2023d-fpga-signal-recognition/README.md)。沿着数据流对照课程、模块和环回演示，比先浏览全部源码更容易把握各部分的作用。该工程使用 ACX720-V3 35T 与 ACM2108，上游记录了六类信号的板上环回演示。

## 从题目走到测量方案

[2019 D电路特性测试仪](../2019-D题-简易电路特性测试仪/README.md) 是一份 STM32F407 / Keil 参考工程。阅读时可以先画出激励、被测电路、采样与结果显示之间的关系，再回到源码寻找每一段的实现。

[2024 B单相功率分析仪方案](../2024/B题-单相功率分析仪-MSPM0G3507实现方案.md) 把问题转向电压、电流与相位测量，适合与前一题比较采样方式和误差处理。

[2013 E频率特性测试仪](../2013-E题-简易频率特性测试仪-番茄派工程/README.md) 保存了调研与 CCS 空工程。可以从扫频、幅相测量和数据显示三个部分拆出任务，再逐步补成自己的系统。
