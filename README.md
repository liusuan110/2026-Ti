# 2026 TI 电赛备赛资产库

这份仓库记录了 2026 年电赛备赛中积累的题目、训练工程和硬件资料。内容围绕信号产生、采集分析、波形重建和电路测量展开，主要使用 MSPM0G3507，也保留了 STM32 和 FPGA 参考工程。

第一次打开工程，先看[从下载到观察一帧数据](docs/QUICKSTART.md)，其中列出了导入位置、板级环境和调试器里要看的变量。阅读资料时，可以从下面三条路线选一个具体任务。2026 F题《李萨如图形显示控制装置》的完整工程与方案说明，集中在 [ti-last](https://github.com/liusuan110/ti-last)。

## 搭起一条信号处理链路

先让数据稳定地采进来：用定时器确定采样节拍，由 DMA 搬运数据，再用 FFT 把时域采样变成频域信息。接着阅读 AD9959 驱动，理解输出频率、相位和幅度怎样设定。最后进入 2023 H题，把采集、识别、重建和相位控制连成一条完整思路。

阅读顺序：[ADC / DMA / FFT 例程](MSPM0例程-双ADC同步采样与FFT/README.md) → [AD9959 资料](AD9959-DDS信号源资料/README.md) → [H题模块化工程](2023-H题-信号分离-番茄派工程/代码/README.md)。

## 理解信号识别与数字解调

2023 D题材料适合研究“采到一段信号后，怎样判断它是什么”。先通过学习包建立特征提取和调制识别的概念，再沿 FPGA 导读进入模块与课程，观察数据如何流经处理链路。

阅读顺序：[2023 D完整学习包](2023-D题-完整学习包.md) → [FPGA 工程导读](2023-D题-FPGA信号识别-学长参考/导读.md)。

## 围绕一道测量题设计系统

仪器仪表类题目把信号源、采样、切换和显示放在同一个测量过程中。2019 D题适合看电路特性如何转成可测量的量；2024 B题可以继续比较功率测量中的幅相与采样问题；2013 E题保留了频率特性测试仪的调研和 CCS 空工程，适合接着推演自己的实现方案。

入口：[2019 D电路特性测试仪](2019-D题-简易电路特性测试仪/README.md) · [2024 B功率分析仪方案](2024/B题-单相功率分析仪-MSPM0G3507实现方案.md) · [2013 E频率特性测试仪](2013-E题-简易频率特性测试仪-番茄派工程/README.md)。
