## 如何理解“资产”

这里同时保存空工程、实现方案、第三方代码、历史编译记录和阶段测试记录。它们的验证程度不同，不能把“代码已收录”“上游称跑通”或“某版本编译通过”统一理解为本队完整实物验收；具体状态见[资产索引](docs/ASSET_INDEX.md)。

H_SignalSep 与 SignalSeparator_v2 的接线、测试和成熟度分别记录，不能混用。MSPM0 例程中的 `14_adc_dma_2ch` 是单 ADC 顺序双通道，不是双 ADC 同步采样。

赛前预测、每日状态和计划保留原日期，按历史材料阅读。两个仓库保持可更新，工程路径和原始资料予以保留；后续复用成果请另开工程并记录来源、工具版本、接线和测试条件。
