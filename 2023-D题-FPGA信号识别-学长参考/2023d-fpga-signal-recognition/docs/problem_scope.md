# 2023D Problem Scope

本仓库围绕“调制方式识别与参数估计”方向进行 FPGA 实现练习。

为避免在公开仓库中复制赛题原文，本文只记录工程所需的抽象目标：

```text
输入：调制信号
处理：识别调制方式，估计相关参数
输出：显示识别/估计结果，并在后续阶段输出解调信号
```

当前工程覆盖的演示信号：

```text
CW
AM
FM
2ASK
2PSK
2FSK
```

当前工程重点：

```text
1. FPGA 内部 DDS/NCO 信号生成
2. DAC -> ADC 环回
3. DDC/IQ 基带处理
4. AM/FM/CW 粗分类与参数估计原型
5. 2ASK/2PSK/2FSK 键控类识别原型
6. ACX720 35T 资源约束下的可上板演示
```

完整赛题请从官方渠道获取，本仓库不再分发题面 PDF 或提取全文。
