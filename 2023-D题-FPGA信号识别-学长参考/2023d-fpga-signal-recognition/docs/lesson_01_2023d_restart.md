# 2023D 第一课：重新认识题目

这道题的名字是：

```text
信号调制方式识别与参数估计装置
```

关键词不是“产生信号”，而是：

```text
识别 + 估计 + 解调输出
```

## 1. 系统里谁负责产生信号

题目中的输入信号叫 `u_M`，它来自“信号发生器”。

```text
信号发生器 -> 你的装置 -> 示波器
```

所以对 2023D 来说，FPGA 不是主角里的“信号源”，而是主角里的“分析仪”：

```text
输入：未知调制信号 u_M
处理：识别调制方式，估计参数
输出：显示结果 + 输出解调信号 u_o
```

硬件没有到的时候，我们用 testbench 或 Python 生成 `u_M` 的采样数据，等价于先假装 ADC 已经把模拟信号采进来了。

## 2. 基本要求要识别哪三种信号

基本要求只考虑三类：

```text
AM
FM
CW
```

公共条件：

```text
载频 f_c = 2 MHz
输入幅度 = 100 mVpp
```

这里的 `2 MHz` 是输入信号的载波频率。和之前误看的 2024C 的 `30~40 MHz` 没关系。

## 3. AM 信号模型

题目说 AM 是“含载频分量的双边带调幅信号”，也就是普通 AM：

```text
u_AM(t) = A_c * [1 + m_a * sin(2*pi*F*t)] * cos(2*pi*f_c*t)
```

其中：

```text
f_c = 2 MHz
F   = 调制信号频率
m_a = 调幅系数，范围 0.3 < m_a < 1
```

基本要求（1）里：

```text
已知是 AM
F = 1 kHz
要求估计 m_a
```

基本要求（4）里：

```text
未知 AM / FM / CW
如果识别为 AM，F 是 1/2/3/4/5 kHz 中的一个
要求估计 F 和 m_a
```

AM 的直观特征：幅度包络在慢慢变大变小。

## 4. FM 信号模型

标准单音 FM 可以写成：

```text
u_FM(t) = A_c * cos(2*pi*f_c*t + m_f * sin(2*pi*F*t))
```

其中：

```text
f_c = 2 MHz
F   = 调制信号频率
m_f = 调频系数，范围 1 <= m_f <= 5
```

瞬时频率会围绕 2 MHz 摆动：

```text
f_inst(t) = f_c + m_f * F * cos(2*pi*F*t)
```

所以最大频偏是：

```text
Delta_f_max = m_f * F
```

基本要求（2）里：

```text
已知是 FM
F = 5 kHz
要求估计 m_f 和 Delta_f_max
```

基本要求（4）里：

```text
未知 AM / FM / CW
如果识别为 FM，F 是 1/2/3/4/5 kHz 中的一个
要求估计 F、m_f 和 Delta_f_max
```

FM 的直观特征：幅度基本不变，但载波周期会被轻微压缩/拉伸。

## 5. CW 信号模型

CW 是连续载波：

```text
u_CW(t) = A_c * cos(2*pi*f_c*t)
```

它没有 AM 的幅度包络变化，也没有 FM 的频率摆动。

基本要求（4）里，如果识别为 CW：

```text
显示字符 "CW"
```

## 6. 无硬件阶段我们先做什么

先不碰 ADC、DAC、引脚约束和板卡时钟。

第一阶段只做数字算法闭环：

```text
软件/仿真生成 u_M 采样
        ↓
模拟 ADC 输出 x[n]
        ↓
识别 AM / FM / CW
        ↓
估计 F、m_a、m_f、Delta_f_max
        ↓
输出用于观察的解调波形
```

建议学习顺序：

1. 用 Python 画出 AM、FM、CW 的波形和特征。
2. 再用 Verilog testbench 产生同样的采样流。
3. 先做 AM 包络检测。
4. 再做 FM 瞬时频率估计。
5. 最后做 AM / FM / CW 自动分类。

## 7. 这一步你需要记住的三个判断

```text
AM：幅度包络会随 1~5 kHz 正弦变化
FM：幅度基本不变，瞬时频率会随 1~5 kHz 正弦变化
CW：幅度和频率都基本不变
```

这就是 2023D 基本要求的核心。
