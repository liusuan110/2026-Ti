## 0. 这是什么 / 出处

- 子文件夹 `2023d-fpga-signal-recognition/` 是 [hewzhew/2023d-fpga-signal-recognition](https://github.com/hewzhew/2023d-fpga-signal-recognition) 的完整克隆(**已去 `.git`,MIT 许可,版权归原作者,仅团队学习参考**)。
- 一位学长为电赛**信号类**做的 **FPGA 软件无线电式调制识别**工程,对应 **2023 国赛 D 题**(调制方式识别 + 参数估计)。
- 质量比它 README 谦虚的"demo"说法重得多:**52 个 Verilog 模块 + 35 节教学文档**。

## 1. 它实现什么

- **识别 6 类**:CW / AM / FM / 2ASK / 2PSK / 2FSK
- **参数估计**:AM 调制度、FM 频偏 + 调制指数、码元速率、FSK 频差 + 调制指数 h
- **现状**:板上闭环(FPGA 内部生成信号 → DA0 →(SMA 环回)→ AD0 → 识别 → LED)

## 2. 系统架构(信号流)

```
内部信号源(dac_2023d_signal_source) → DAC0 ──SMA环回── ADC0(8bit)
  → 去直流(−128) → NCO前端(载波cos/sin + 5路参考音)
  → DDC下变频→I/Q → 滑动平均/抽取(降到 250kHz 基带)
  → CORDIC atan2→瞬时相位 → 解缠 / 相位斜率(FM)
  → 幅度(AM) / 5音调评分(Goertzel式,FSK/键控) / 跳变率(码元速率)
  → 粗分类(AM/FM/CW)+ 键控分类(2ASK/2PSK/2FSK)
  → signal_kind + 各参数 → LED
```

## 3. 算法路线

**确定性 DSP,不是深度学习**:DDC 下变频 + CORDIC 求相位 + 音调评分 + 跳变率判决。可解释、省资源、上板稳——比塞神经网络更适合电赛和 FPGA。

## 8. 完成度 + 缺口

| 已完成 ✅ | 仍缺 ⚠️ |
|---|---|
| 6 类识别 + 参数估计、上板验证、完整 DSP 链、仿真 + 构建脚本、35 课文档 | 外部信号输入(现为内部生成环回)、模拟前端/保护/幅度自适应、参数屏幕显示(现仅 LED)、解调输出、稳健性/边界 |

**资源约束**:35T 已用 **~93% LUT**,几乎没空间再加 ILA/屏幕/复杂算法。要扩展需**换更大 FPGA(如 7A100T)或大改优化**。

## 9. 对我们的价值 + 注意点

**价值**:正对口信号类;35 课是现成的 FPGA-DSP 教材;MIT 可借鉴(注明出处)。

**注意**:
1. **它把人绑在 FPGA 路线上**。**2026 模拟专题赛多为封闭指定平台,FPGA 可能用不上** → 这份更适合**冲国赛/开放省赛**,或作为**长期 FPGA 能力建设 + 学习教材**。
2. 现在是**自发自收**;真实赛要测**外部未知信号**,前端 + 输入是最大工作量(作者也还没做)。
3. 8 位 ADC + 35T 资源紧,要达标参数精度 + 屏显需更好前端 + 更大 FPGA。
4. **MSPM0 对照**:低频/窄带信号,这套"DDC+I/Q+相位/幅度判决"的思路也能搬到 MSPM0(用片上 ADC + CMSIS-DSP);高带宽/高采样才必须 FPGA。

## 10. 给做 FPGA 队员的上手路线

1. 先跑通至少一个仿真脚本(`run_*_xsim.ps1`)
2. 读 `top → receiver_stream_core → receiver_full_scope_pipeline` 把数据流走通
3. 按 `docs/` lesson 顺序补 DSP 原理
4. 先在**仿真里改参数 / 换输入信号**验证,再上板
5. 要扩到外部输入:先解决**模拟前端(放大/抗混叠/幅度自适应)** + **更大 FPGA**
