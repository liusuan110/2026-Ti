# MSPM0 例程:双 ADC 同步采样 + FFT(B 题用)

> 用途:为 B 题《单相功率分析仪》(见 [`2024/B题-...实现方案.md`](../2024/))准备的 MSPM0G3507 代码骨架——ADC 采样 + 整周期触发 + FFT 谐波分析。
> 来源:[Raoxiuyu/TI-MSPM0G3507-code](https://github.com/Raoxiuyu/TI-MSPM0G3507-code)(CCS 工程,许可证以原仓库为准)。
> 整理:2026-06-06,从原仓库挑出 3 个例程,**已删除各自的 `Debug/` 编译产物**(只保留源码 + SysConfig + 工程文件)。

---

## 包含的三个例程

| 例程 | 作用 | 对 B 题的用法 |
|---|---|---|
| **14_adc_dma_2ch** | ADC + DMA **双通道**采集 | 同时采"电压 v" 和 "电流 i" 两路 |
| **15_adc_dma_time_trigger** | **定时器触发** ADC 转换 | 配过零检测做**整周期同步采样**(谐波/THD 准的关键) |
| **12_FFT** | FFT 变换 | 算基波 + 2~10 次谐波有效值 + THD |

> 组合思路:**15(定时触发 → 整周期) + 14(两路 v/i) + 12(FFT 谐波)** = B 题"采集 + 分析"核心。

---

## ⚠️ 重要:14_adc_dma_2ch 是"单 ADC 2 通道",不是"真双 ADC 同步"

经核对源码,**14 用的是单个 ADC 实例(ADC12_0)轮流采 2 个通道**,两路之间存在**微小时间差(顺序转换)**,会给有功功率 P、功率因数 PF 带来系统性相位误差。

B 题要 P/PF ≤±1%,两种处理(任选其一):
1. **软件相位补偿**:用纯阻性负载(真实 PF=1)标定,补偿这点固定时间差/相位差(实现方案文档第 7.3 节)。
2. **改成真·双 ADC 同步(更优)**:MSPM0G3507 有 **ADC0、ADC1 两个实例,支持同一硬件事件同时触发**——在 SysConfig(`empty.syscfg`)里把电压走 ADC0、电流走 ADC1,用同一个定时器事件触发,两路**同一时刻采样、零时间差**。这是功率测量的理想做法。

`15_adc_dma_time_trigger` 已演示"定时器触发 ADC",把它扩展成"同一定时器同时触发 ADC0+ADC1"即可实现方案 2。
