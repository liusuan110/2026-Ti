# MSPM0 采样与 FFT：三份独立 CCS 训练工程

这一组例程适合把 ADC、DMA、定时触发与 FFT 分开看清，再把它们带进信号处理或测量题。目录沿用收录时的名称，下面按每份代码实际展示的内容组织入口。

## 先读哪一份

| 例程 | 先理解什么 | 第一次实验看什么 |
| --- | --- | --- |
| [15_adc_dma_time_trigger](15_adc_dma_time_trigger/README.md) | 定时器事件怎样触发 ADC | 触发配置与 `gADCSamples` |
| [14_adc_dma_2ch](14_adc_dma_2ch/README.md) | 一个 ADC 顺序转换两路，FIFO 与 DMA 怎样存数据 | 两个输入在数组中的实际排列 |
| [12_FFT](12_FFT/README.md) | 一帧数据怎样去直流、做 FFT、计算模值 | 采样数组、FFT 输入与频谱峰值 |

想从采样时刻学起，按 15 → 14 → 12 阅读；想先看到频谱，可以直接进入 12。三个子目录各有完整的数据流和调试观察点。

## 工程环境

三份工程保存于同一套环境：

| 项目 | 保存的配置 |
| --- | --- |
| 编译器 | TI Arm Clang 3.2.2 LTS |
| SDK | MSPM0 SDK 2.01.00.03 |
| SysConfig | `empty.syscfg` 生成记录为 1.20.0；工程 Products 保留 1.19.0 |
| 封装 / 外部时钟 | LQFP-64(PM) / 24 MHz HFXT |
| 工程元数据 | `.project/.cproject/.ccsproject` |

在 CCS 的 **Import CCS Projects** 中，把搜索目录定位到某一子工程文件夹。导入后选定本机配置工具，打开 `empty.syscfg` 重新生成配置，再读 `empty.c` 与 `Hardware/adc.c`。图示和目录例子见[第一次打开工程](../docs/QUICKSTART.md#ccs-中的两种入口)。

移到自己的开发板时，先对照封装、时钟与 ADC 引脚；采样率随时钟和触发配置确定，算法中的频率换算也随之更新。

## 从例程走向完整测量

14 号例程用一个 ADC 依次转换两个通道。把它用于电压、电流或相位测量时，需要考虑通道间的时间差；继续研究双 ADC 同一事件触发与通道相位标定，可以参考[2024 B题功率分析仪方案](../2024/B题-单相功率分析仪-MSPM0G3507实现方案.md)。

15 号例程展示固定节拍，整周期采样还需要输入周期信息与采样窗口配合。12 号例程得到频谱模值，进一步计算 RMS 和 THD 时再补幅度归一化与谐波统计。三个例程分别提供了进入这些问题的起点。

到 [H题工程](../2023-H题-信号分离-番茄派工程/代码/README.md) 中，可以继续看采集结果怎样参与识别，再把频率、相位等参数交给 DDS 重建输出。
