## 2. 算法流程(README 的"三步走",对应 main.c)

```
① 采集与分析判断
   ADC+DMA(TIM3触发,2MHz采样,采6000点≈3ms)采混合信号 C
   → cal_2frqs()  : 对19个候选频率(10~100k/5k)做正交相关(matched filter,非FFT找峰)→ fA, fB
   → fft_cal_2types(): 1024点FFT,看 3次/5次谐波能量比 → 判正弦(0)/三角(1)(FFT 仅用于判波形)
② 信号重建
   按 fre + wave_type 从查表(DAC_SIN[] / Tri_Wave[])填 DAC 缓冲
   → TIM4/TIM6 触发 双DAC(DA1/DA2)输出 A'、B'
   → 两定时器同时启动,保证 DA 初相无偏移
③ 相位差计算与实时相位校正(← 同频显示的关键)
   while(1) 持续重采 → get_pos_angle()(atan2 算相位差)
   → 换算成延时 → 改 TIM4/TIM6->CNT 对齐相位 → 抑制漂移
   基础部分:让 A'/A、B'/B 同相;  发挥部分:按 change_phi 设定相位差
```

## 4. 关键技术点(值得抄的)

1. **波形判别(正弦 vs 三角)**:看 **3次/5次谐波** 与基波能量比 + 阈值。三角波有显著 3/5 次谐波,正弦几乎没有。`fft_cal_2types()` 里实现,**直接可移植**。
2. **同频显示靠"改相位"不是"改频率"**:重建用整数倍频率,靠 **TIM 精准延时(改 CNT)** 实时把 A'/A 相位对齐 → 示波器上不漂。这是 H题最大难点的工程解。
3. **重建用内置 DAC + 查表**(DAC_SIN/Tri_Wave 表),TIM 触发 DMA 刷 DAC。
4. **相位负值处理**:atan2 给 -π~π,DAC 无法"提前"相位 → 负相位时延迟一整个周期(求补)。

## 5. 坑(README + 代码注释)

- **TIM 位数**:延时用 16 位 `CNT`(65535),溢出/求补要算对。
- **STM32 爆栈**:栈太小会让 **DA 波形出问题**(README 明确警告)。
- 采样点数 / FFT 点数 / 频率分辨率要匹配(2MHz 采样、6000点采集、1024点FFT)。

## 6. 和你「番茄派 MSPM0 + AD9959」方案的对照(最该看的一节)

| 环节 | SHR-sky(STM32) | 你的番茄派 + AD9959 |
|---|---|---|
| 测频 | 对19个候选频率做正交相关(matched filter) | FFT 找峰 + 抛物线插值(可测偏网格频率) |
| 波形判别(正弦/三角) | 3/5次谐波能量比 | 同思路,完全通用(已加重叠去污) |
| 重建 A'/B' | 内置 DAC + 查表 | AD9959 DDS(频率精度 0.116Hz、更纯净) |
| 相位对齐 / 同频显示 | TIM 延时改 CNT(巧但繁);DAC 与 ADC 同一时钟域 | AD9959 相位字 + 软件 PLL(AD9959 自带独立晶振会漂,须闭环锁相) |
| 相位差控制(发挥②) | change_phi → TIM 延时 | AD9959 14bit 相位字,0.022° 分辨率,天生支持 |

> 结论:这份工程的前半(采集+测频+波形判别)思路直接搬到番茄派(测频可借鉴它的相关法与 FFT 互验)。
> 后半(重建+相位)用 AD9959:相位差控制确实是 AD9959 的强项;但注意 AD9959 有自己的晶振,与信号源、MSPM0 三时钟域独立,
> 同频锁定不能只"设一次相位字",必须软件 PLL 闭环(本工程已实现)。STM32 的 DAC 与 ADC 同一时钟域,反而少一层漂移。

## 7. 上手路线

1. 先读 `S08_报告.pdf` 看整体框图和设计取舍。
2. 读 `main.c` 把"采集→FFT→重建→相位校正"主流程走通(配合本导读 §2)。
3. 重点抠 `fft_cal_2types()`(波形判别)和 `get_pos_angle()`(相位计算)——这两段最值钱、最通用。
4. 在番茄派上**先复刻"采 C → FFT 测 fA/fB/幅度/波形"**,验证能不能稳定测出两路参数。
5. 再接 **AD9959 重建 A'/B'**,用相位字做同频对齐和发挥②的相位差。
6. 配合仓库 `AD9959-DDS信号源资料/` 的驱动 + `MSPM0例程-双ADC同步采样与FFT/` 的采集FFT骨架。
