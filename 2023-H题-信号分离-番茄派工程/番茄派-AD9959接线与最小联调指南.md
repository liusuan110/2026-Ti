# 番茄派 MSPM0G3507 与 AD9959 接线与最小联调指南

## 一句话结论

当前 H 题番茄派工程已经写好了 AD9959 驱动，连接方式不是硬件 SPI 外设，而是 5 根 GPIO 模拟串行时序：

`PA7=SCLK`、`PB2=SDIO0`、`PB3=CS`、`PA8=IO_UPDATE`、`PA9=RESET`，再加公共地和 AD9959 模块供电。

先把 AD9959 单独跑通，再接 AD835、滤波、闭环锁相部分。

## 必接线

| AD9959 模块端 | 番茄派 MSPM0G3507 端 | 作用 | 备注 |
|---|---|---|---|
| GND | GND | 公共地 | 必须共地，否则所有时序都不可靠 |
| SCLK | PA7 / DDS_SCLK | 串行时钟 | 软件 SPI 输出 |
| SDIO0 / SDIO / DATA | PB2 / DDS_SDIO0 | 串行数据 | 当前工程只用 3 线串行模式 |
| CS / CSB | PB3 / DDS_CS | 片选 | 低有效 |
| IO_UPDATE / UPDATE | PA8 / DDS_UPDATE | 寄存器更新 | 写完频率/相位/幅度后打一拍 |
| RESET / RST | PA9 / DDS_RST | 复位 | 初始化时由代码控制 |
| VCC / 5V / 3V3 | 按模块丝印供电 | 模块电源 | AD9959 IO 是 3.3V 逻辑，模块电源按板子标注接 |

当前工程使用 SDIO0 单线写寄存器；资料和代码注释里提到 AD9959 其余数据脚接 GND。P0-P3 是调制/profile 选择脚，H 题当前基本输出和重建流程不需要先接。

## 四路输出怎么用

| AD9959 输出 | H 题工程中的用途 |
|---|---|
| CH0 / OUT0 | 重建输出 A' |
| CH1 / OUT1 | 重建输出 B' |
| CH2 / OUT2 | 模拟闭环/PID 模式下给 AD835 的正交参考 |
| CH3 / OUT3 | 模拟闭环/PID 模式下给 AD835 的正交参考 |

如果只是验证番茄派能不能控制 AD9959，先只看 CH0/CH1 的正弦输出即可，不要一开始就把 AD835、低通、ADC1 闭环全接上一起排错。

## 最小联调流程

1. 确认 AD9959 模块晶振。
   仓库代码默认按 25 MHz 晶振、内部 PLL x20 计算，也就是 500 MHz 系统时钟。如果模块晶振不是 25 MHz，需要同步修改 `代码/User/AD9959.c` 的 `ACC_FRE_FACTOR`，以及 `代码/app/pll.h` 里的 DDS 参考频率配置。

2. 先确认番茄派工程本身能跑。
   把 `代码/app/h_config.h` 中 `H_STAGE` 设为 1 或 2，先验证 ADC、串口日志、基础分析流程，不把 DDS 问题和采集问题混在一起。

3. 接上 AD9959 的 5 根控制线和 GND。
   推荐上电顺序是先给 AD9959 模块上电，再给番茄派上电或复位番茄派。仓库资料里特别提醒过：如果 AD9959 在 MCU 后上电，内部 PLL 可能没有按预期初始化，输出频率会不对。

4. 把 `H_STAGE` 设为 3，验证开环重建输出。
   这一步目标只看 AD9959 能否被番茄派设置频率、相位、幅度。示波器先接 CH0/CH1，看有没有稳定输出。

5. AD9959 开环输出稳定后，再进入 `H_STAGE=4`。
   默认工程的 `H_LOCK_METHOD` 是模拟 PID 锁相，此时才需要把 CH2/CH3、AD835、低通滤波、偏置和 ADC1 反馈链路一起接入。

## 如果没有输出，按这个顺序查

1. AD9959 和番茄派是否共地。
2. AD9959 模块电源是否符合模块丝印，且先于 MCU 上电或已重新复位 MCU。
3. `SCLK=PA7`、`SDIO0=PB2`、`CS=PB3`、`UPDATE=PA8`、`RST=PA9` 是否接反，特别注意模块上可能写的是 `CSB`、`IOUP`、`IO_UPDATE`。
4. 用示波器或逻辑分析仪看 PA7/PB2/PB3/PA8 是否在初始化时跳变。
5. 看 `代码/User/AD9959.h` 和 `代码/H_SignalSep.syscfg` 中的 GPIO 名称是否仍是 `DDS_SCLK`、`DDS_SDIO0`、`DDS_CS`、`DDS_UPDATE`、`DDS_RST`。
6. 若有波形但频率不对，优先查晶振频率、PLL 倍频和 `ACC_FRE_FACTOR`。
7. 若低频输出幅度异常，注意 AD9959 模块输出常带隔直电容，不能直接驱动低阻负载；后级要用合适的缓冲、滤波和幅度调理。
