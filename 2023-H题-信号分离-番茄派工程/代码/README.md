# 代码

番茄派 MSPM0G3507 工程(CCS):
- ADC + DMA 采集 C(fs=1.024MSa/s,N=1024)
- FFT 分析:频率(寻峰/排序)+ 波形(3/5 次谐波比),定点 q15 + MATHACL
- AD9959 控制:再生 A'/B'(`setFreq/setAmp/setPhase`)
- **软件 PLL**:鉴相(IQ/乘法器)+ PI 环路 + 调 FTW(带预调谐 `FTW=预设+环路输出`)
