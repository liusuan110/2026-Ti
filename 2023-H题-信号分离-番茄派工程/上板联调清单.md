# 2023 H题 — 番茄派上板联调清单

> 板子到手照此调。代码侧能离板验证的都已验过(零编译错误 + PLL 仿真 6/6 + 信号链 host 10/10)。
> 上板风险几乎全在:硬件接线 + 三处标定(fs / AD9959 晶振 / MATHACL 相位刻度)+ 反馈通道接线与两路同步。
> 头号问题:反馈通道硬件未接(代码已就绪,见下「必修1」)——不接它"同频稳定显示"做不出来。

---

## 推荐调试顺序
1. 能跑起来:上电不死机(时钟已改片内 SYSOSC,无需外部时钟)、SWD 能烧录。
2. 采集对:示波器确认 ADC 进的是真信号 → 标定 fs(必修4)。
3. 分析对:调试器/串口打印 `s_res`,确认两路 频率/波形/相位 测得准(此时先不接 DDS)。
4. 重建对:接 AD9959,按测得频率出 A′/B′(查晶振 必修3、字节序 建议5)。
5. 再上闭环:接反馈通道(必修1)→ 测控制周期 dt 重调增益(建议1)→ 调相位刻度(建议2)→ 同频锁定。

---

## 常见问题:症状 → 排查(带着板子照这个查)

### 必修:必先处理(不弄好"同频显示"根本不工作)

| # | 症状 | 原因 | 排查 / 解决 |
|---|---|---|---|
| 1 | A′/B′ 能出,但相对 A/B 持续漂移,示波器上不稳;相位差也无从控制 | 反馈通道硬件未接(代码已就绪)。固件已实现:第2路 ADC(ADC1)与 C 近同步采 A′+B′(`SigAcq_captureDual`)+ 在已知 bin 处提取反馈相位(`SigAnalysis_phasesAtBins`),`H_App_measureFeedback` 已是真实提取。差的是硬件接线 | 把 A′+B′ 经运放引回 ADC1 输入(硬件);确认 ADC1 引脚(代码占位 `H_FB_CHAN`/`H_FB_PIN_IOMUX`,见 `sig_acq.c`);标定两路采样同步(现双软件启动 ~百 ns 残差,小且基本恒定可补偿;要零时间差就升级成同一 TIMG 事件同时触发 ADC0/ADC1) |
| 2 | 采到的全是噪声/零,频率波形全错 | ADC 输入引脚不对 | `sig_acq.c` 写死 `CHAN_2 = PA25 (PINCM55)`。对照番茄派丝印确认 C 进的引脚;不符改 `H_ADC_CHAN`/`H_ADC_PIN_IOMUX` |
| 3 | DDS 无输出/乱,或频率整体按比例偏 | AD9959 接线错;或晶振不是 25MHz(有些模块 20/30MHz),`ACC_FRE_FACTOR=8.589934592` 是按 25M×20=500MHz 算的 | 确认 5 根控制线(SCLK=PA7 / SDIO0=PB2 / CS=PB3 / UPDATE=PA8 / RST=PA9);翻模块看晶振,不是 25MHz 就改 `ACC_FRE_FACTOR`(User/AD9959.c)和 `PLL_DDS_REF_HZ`(app/pll.h) |
| 4 | 频率读数偏 2~3kHz、跨过 5kHz 网格 → 重建频率错 | 采样率 fs 未标定;`H_ADC_FS_HZ=1024000` 只是按 SYSOSC 32MHz+采样窗的估算 | 给已知频率(如 50kHz)采一块做 FFT,看峰落第几个 bin `k`,反算 `fs=已知频率×N/k`(N=1024),写回 `app/h_config.h` 的 `H_ADC_FS_HZ`。想严格锁率可改 TIMG 事件触发(见 sig_acq.c TODO) |

### 建议:很可能要调

| # | 症状 | 原因 | 排查 / 解决 |
|---|---|---|---|
| 1 | 闭环不收敛 / 相位乱跳 / 越调越飘 | PLL 增益按 dt≈5ms 整定,实际控制周期不同(仿真证 dt=50ms 会发散) | 上板测一轮 `H_App_loop` 实际耗时,设好 `app/h_app.c` 的 `H_LOOP_PERIOD_MS`(须 ≥ 处理时间),再用 `host_test/test_pll.c` 以该 dt 重跑增益扫描,改 `app/pll.h` 的 `PLL_KP_SHIFT/PLL_KI_SHIFT` |
| 2 | 频率对、但相位/同相对齐不准 | MATHACL 相位刻度假设未实测:`Recon_angleQ31ToCpow` 假设归一化角 `0x40000000=90°` | 给一对已知相位差的信号,看重建相位是否符合;不符只需改该函数的移位位数(现 `>>18`,app/reconstruct_core.c) |
| 3 | 不接信号就上电,却"锁"到了噪声 | ANA-2 自适应归一化会把噪声也放大到满量程;首帧校验(`result_ok`)只查频率范围+valid,不查信噪比 | 建链前加幅度/SNR 阈值:在 `h_app.c` 的 `result_ok()` 里加 `s->amp > 阈值` 判据 |
| 4 | A′/B′ 幅度不够 1Vpp,或采集削顶 | AD9959 单端约 ±0.5Vpp 需后级放大;C 输入未偏置到中点或超 0~3.3V | 后级运放把 A′/B′ 放到 ≥1Vpp;C 调理到直流偏置 ~1.65V(对应码 2048)且不超量程,加抗混叠 LPF(~150–200kHz) |
| 5 | 重建频率不对(且晶振已确认对) | 新增的 `Reconstruct_setFtw`(整数直写 FTW:CSR 选通道 + CFTW0 大端4字节)字节序/寄存器序列未上板验证 | 用逻辑分析仪看 SPI 写出的 FTW;或先用驱动 float 路径 `Reconstruct_setFreqHz` 对比 |
| 6 | 块边界相位抖动 | `SigAcq_capture`/`captureDual` 的 FIFO flush(disable/enable FIFO)清空语义/时序未上板验证(ACQ-4) | 看连续两块拼接处有无陈旧样本;必要时改成读空 FIFO 或加 settling 等待 |
| 7 | 采集卡死不返回 | DMA_DONE 中断没触发(NVIC/中断号/向量) | startup 已纳入(BUILD-1)向量应在;查 `ADC0_INT_IRQn`/`ADC1_INT_IRQn`、`NVIC_EnableIRQ`、DMA 触发源配置 |

### 低危 / 边界情况

| 症状 / 项 | 说明 |
|---|---|
| 三角波出不来 | AD9959 只出正弦,三角需模拟硬件(比较器整型→积分器→幅度补偿),固件给不了;做发挥①时搭这条模拟链(见第1节硬件) |
| 时钟略飘 | 已改片内 SYSOSC ±2%,CPUCLK 80MHz/SysTick 1ms 略偏 —— 频率靠标定、相位靠闭环,无碍 |
| 负相位差 0.022° 级误差 | `Recon_degToCpow` 负角舍入(RECON-1),远小于 5° 要求 |
| 运行 >49.7 天异常 | `Tick_delay` 计数回绕(SYS-2),竞赛时长内无感;`h_app` 主循环节拍已用回绕安全写法 |

## 详细分步

### 0. 前提
- [ ] CCS 导入 `代码/H_SignalSep.projectspec` 能 Build + 下载(见 `代码/README.md`)。startup 已纳入 projectspec(BUILD-1),不会缺 `_c_int00`。
- [ ] 番茄派、AD9959 模块、运放(NE5532/OPA)、示波器、(可选)信号源就位。

### 1. 硬件搭建
- [ ] 加法器(基本①):NE5532 增益 1 加法器 `C=A+B`,参考 `培训资料/NE5532缓冲&放大板.pdf`。
- [ ] C 输入调理:调到 ADC 量程(0~3.3V,偏置 ~1.65V/中点)+ 抗混叠 LPF(~150–200kHz)。
- [ ] AD9959 输出:重构 LPF + 运放缓冲,A′/B′ 各 ≥1Vpp(见 `AD9959-DDS信号源资料/02-硬件接口与电路设计.md`)。
- [ ] PLL 反馈(必需):把 A′+B′ 经运放引回 ADC 第 2 路通道(ADC1),同频显示必需,见「必修1」。
- [ ] 三角波电路(发挥①):AD9959 正弦 → 比较器整型 → 积分器 → 幅度补偿 → 模拟开关切换正弦/三角。

### 2. 上电
- [ ] MCU 时钟:已改片内 SYSOSC→SYSPLL=80MHz(BUILD-3),无需 PA6 外部时钟,上电即起振。
- [ ] AD9959 先于单片机上电(否则其 25M→500M PLL 时钟错;学长 README 警告);确认其 PLL=500MHz(对应 `ACC_FRE_FACTOR`,见「必修3」)。

### 3. 基础联调:采集 + 标定
- [ ] ADC 引脚:确认 C 接到 `sig_acq.c` 所配引脚(见「必修2」)。
- [ ] 采集验证:给已知正弦,调试器看 `s_buf[]`,确认波形完整、无削顶、噪声可控。
- [ ] fs 标定(关键):见「必修4」,标定后频率才准。

### 4. 分析验证(`sig_analysis`)
- [ ] 固定输入(50k 正弦 + 100k 正弦),看 `h_result_t`:`freq_hz`/`wave` 对不对。
- [ ] 换三角;换 fB=3·fA(10k+30k、20k+60k)确认仍判对(谐波重叠去污 ANA-3 已离板验证;含幅度悬殊正弦小被误判三角的修正)。
- [ ] 阈值不准调 `sig_analysis_core.h` 的 `SIGCORE_HARM_THRESH`(现 40)。
- [ ] (汉宁窗 + 块归一化 ANA-2 已加;离 bin 频率误差离板实测 ±53Hz,在 bin 精确。)

### 5. 重建验证(`reconstruct`)+ MATHACL 相位刻度
- [ ] 按分析结果让 AD9959 出 A′/B′,量频率/幅度对不对。
- [ ] 确认 MATHACL 相位刻度(见「建议2」)。FTW/CPOW 换算本身离板已验证(18/18),重点是这条刻度假设。

### 6. 同频稳定显示(核心难点)+ PLL 闭环
> PLL 已重写为 II 型数字锁相环(`pll_core.c`,调 FTW 做频率+相位联合锁定,误差=原信号相位 vs 反馈相位),
> 反馈相位提取代码已就绪(`SigAnalysis_phasesAtBins`),离板仿真验证收敛(6/6,稳态相位误差 ~0.35°)。上板要做的是接通反馈硬件 + 整定:
- [ ] 先开环看漂移:重建 A′ 后对比 A′/A,因三晶振独立会缓慢漂移。
- [ ] 接反馈通道硬件 + 标定两路同步:见「必修1」(头号)。
- [ ] 测 dt + 重整定增益:见「建议1」。
- [ ] 验证锁定:`pllcore_t.locked` 置位、`last_perr` 收敛到 ~0;示波器 A′/A、B′/B 长时间稳定不漂。

### 7. 发挥①:三角波
- [ ] 判出三角时走三角波硬件链(第1节),A′/B′ 为三角、无明显失真。

### 8. 发挥②:相位差控制
- [ ] `Reconstruct_setPhaseDiffDeg(idx, ref_cpow, deg)` 设 B′ 相对 A′ 相位差(0~180°,5° 步进);或经 PLL 的 `phi_target`。
- [ ] 量实际相位差,误差 ≤5°(换算分辨率离板 0.0098°,主要看硬件/刻度)。

### 9. 逐条对照题目验收
- [ ] 基本①:增益 1 加法器 C=A+B。
- [ ] 基本②:A、B 正弦 50k/100k,分离 A′/B′ 峰峰值 ≥1V。
- [ ] 基本③:正弦、10kHz 整数倍,正确分离。
- [ ] 发挥①:正弦/三角、5kHz 整数倍,正确分离。
- [ ] 发挥②:fB 为 fA 整数倍时,B′/A′ 相位差 0~180°、分辨率 5°、误差 ≤5°。

## 待硬件确认的假设(汇总)
1. PLL 反馈通道接线 + ADC1 引脚 + 两路同步标定(必修1)—— 同频显示前提,头号(代码已就绪)。
2. fs 实际值(必修4)—— 影响所有频率读数。
3. ADC 引脚对应番茄派哪个排针(必修2)。
4. AD9959 晶振=25MHz / PLL=500MHz(必修3)—— 影响输出频率。
5. MATHACL ARCTAN2 相位刻度(建议2)—— 影响相位/同频对齐。
6. PLL 实际控制周期 dt + 据此整定的增益(建议1)。
7. `Reconstruct_setFtw` 字节序、FIFO flush 时序(建议5/6)实测确认。
8. 波形判别阈值 `SIGCORE_HARM_THRESH`(第4节)实测微调。
