# 2023 H题 — 番茄派上板联调清单

> 板子到手照此调。代码侧能离板验证的都已验过(零编译错误/告警含 -Wall + 离板 host:PLL 6/6 · 信号链 11/11 · 重建 18/18 · 遥测 31/31 · 串口屏 46/46)。
> 上板风险几乎全在:硬件接线 + 两处标定(AD9959 晶振 / MATHACL 相位刻度;★不含 fs —— fs 已由定时器精确确定)+ 反馈通道接线。
> 头号问题:反馈通道硬件未接(代码已就绪,见下「必修1」)——不接它"同频稳定显示"做不出来。

> **新增三大上板利器(都已离板验证、编译通过):**
> - **串口遥测**:上电后每控制周期经 UART(默认 PA10 TX,115200 8N1)打印一行诊断 —— 各通道 ADC min/mean/max、两路频率/波形/相位/bin、PLL 误差/FTW/锁定。**取代"挂 JTAG 翻内存"的盲调,这是本次最该用上的工具。** 接 USB-TTL 到 PA10,串口助手即可看。
> - **分阶段 bring-up**(`app/h_config.h` 的 `H_STAGE` 1→4):逐级排错,每级是上一级的超集。改一个宏重新烧即可。
> - 另:**双 ADC 已改定时器(TIMA0)同时触发** → 两路零时间差(发挥②相位差≤5° 的关键),且 **fs 稳定 = 80MHz/78 = 1025641 Hz**(不再靠估算漂);**测得频率吸附到 5kHz 网格**,中和片内 SYSOSC ±2% 误差。

## 推荐调试顺序(配合 `H_STAGE` + 遥测,逐级推进)
1. **能跑 + 串口通**:上电不死机(片内 SYSOSC,无需外部时钟)、SWD 能烧录;串口助手收到启动横幅 `# H-SignalSep telemetry up...`。收不到先查 UART 接线/波特率/共地。
2. **`H_STAGE=1` 采集对**:遥测看 `C=min/mean/max` —— 给已知正弦,均值应≈2048(中点)、不贴 0/4095(不削顶)、min≠max(有信号)。引脚不对见必修2。
3. **`H_STAGE=2` 分析对**:遥测看 `f / w / ph / k(bin)` —— 固定输入,确认两路频率/波形测得准(此时不接 DDS)。fs 已由定时器定,网格吸附后频率应直接落 5kHz 整数;`k`(原始 bin)可反查实际 fs。
4. **`H_STAGE=3` 重建对**:接 AD9959,开环出 A′/B′,量频率/幅度(查晶振 必修3、字节序 建议5)。
5. **`H_STAGE=4` 上闭环**:接反馈通道(必修1)→ 遥测读帧间隔定 dt、必要时重调增益(建议1)→ 调相位刻度(建议2)→ 看 `L=1`(锁定)、`e`(perr)收敛 → 同频锁定。

## 常见问题:症状 → 排查(带着板子照这个查)

### 必修:必先处理(不弄好"同频显示"根本不工作)

| # | 症状 | 原因 | 排查 / 解决 |
|---|---|---|---|
| 1 | A′/B′ 能出,但相对 A/B 持续漂移,示波器上不稳;相位差也无从控制 | 反馈通道硬件未接(代码已就绪)。固件已实现:第2路 ADC(ADC1)与 C **定时器同时触发**采 A′+B′(`SigAcq_captureDual`)+ 在已知 bin 处提取反馈相位(`SigAnalysis_phasesAtBins`),`H_App_measureFeedback` 已是真实提取。差的是硬件接线 | 把 A′+B′ 经运放引回 ADC1 输入(硬件);确认 ADC1 引脚(代码占位 `H_FB_CHAN`/`H_FB_PIN_IOMUX`,见 `sig_acq.c`)。**两路同步已由定时器(TIMA0 事件同时触发 ADC0/ADC1)做到零时间差,不必再标定**(`H_ACQ_USE_TIMER_TRIGGER=1`;代码用"停表→两路使能→启表"杜绝错位一个采样点;上板用双踪示波器抓两路采样沿确认对齐即可)。若定时器路径异常可置 0 退回软件触发 |
| 2 | 采到的全是噪声/零,频率波形全错 | ADC 输入引脚不对 | `sig_acq.c` 写死 `CHAN_2 = PA25 (PINCM55)`。对照番茄派丝印确认 C 进的引脚;不符改 `H_ADC_CHAN`/`H_ADC_PIN_IOMUX` |
| 3 | DDS 无输出/乱,或频率整体按比例偏 | AD9959 接线错;或晶振不是 25MHz(有些模块 20/30MHz),`ACC_FRE_FACTOR=8.589934592` 是按 25M×20=500MHz 算的 | 确认 5 根控制线(SCLK=PA7 / SDIO0=PB2 / CS=PB3 / UPDATE=PA8 / RST=PA9);翻模块看晶振,不是 25MHz 就改 `ACC_FRE_FACTOR`(User/AD9959.c)和 `PLL_DDS_REF_HZ`(app/pll.h) |
| 4 | 频率读数偏 2~3kHz、跨过 5kHz 网格 → 重建频率错 | 定时器模式下 fs 已稳定精确(= 80MHz/(TIMER_ADC LOAD+1) = 80e6/78 = 1025641 Hz,见 `H_ADC_FS_HZ`),不再漂;但片内 SYSOSC ±2% 仍使绝对 fs 有偏 → 已用**频率吸附 5kHz 网格**(`H_FREQ_SNAP_GRID=1`)中和:±2%×100k=2kHz < 2.5kHz 半格,吸附后还原真值 | 一般无需动。若仍偏:遥测看原始 `k`(bin,吸附前),给已知 50kHz 看 `k`,核 `fs=50000×1024/k`;偏差大再改 `H_ADC_FS_HZ`(并按注释同步 syscfg 定时器周期)。极端误差>2.5%才会吸附到错网格 |

### 建议:很可能要调

| # | 症状 | 原因 | 排查 / 解决 |
|---|---|---|---|
| 1 | 闭环不收敛 / 相位乱跳 / 越调越飘 | PLL 增益按 dt≈5ms 整定,实际控制周期不同(仿真证 dt=50ms 会发散) | 上板测一轮 `H_App_loop` 实际耗时,设好 `app/h_app.c` 的 `H_LOOP_PERIOD_MS`(须 ≥ 处理时间),再用 `host_test/test_pll.c` 以该 dt 重跑增益扫描,改 `app/pll.h` 的 `PLL_KP_SHIFT/PLL_KI_SHIFT` |
| 2 | 频率对、但相位/同相对齐不准 | MATHACL 相位刻度假设未实测:`Recon_angleQ31ToCpow` 假设归一化角 `0x40000000=90°` | 给一对已知相位差的信号,看重建相位是否符合;不符只需改该函数的移位位数(现 `>>18`,app/reconstruct_core.c) |
| 3 | 不接信号就上电,却"锁"到了噪声 | ANA-2 自适应归一化会把噪声也放大到满量程;首帧校验(`result_ok`)只查频率范围+valid,不查信噪比 | 建链前加幅度/SNR 阈值:在 `h_app.c` 的 `result_ok()` 里加 `s->amp > 阈值` 判据 |
| 4 | A′/B′ 幅度不够 1Vpp,或采集削顶 | AD9959 单端约 ±0.5Vpp 需后级放大;C 输入未偏置到中点或超 0~3.3V | 后级运放把 A′/B′ 放到 ≥1Vpp;C 调理到直流偏置 ~1.65V(对应码 2048)且不超量程,加抗混叠 LPF(~150–200kHz) |
| 5 | 重建频率不对(且晶振已确认对) | 新增的 `Reconstruct_setFtw`(整数直写 FTW:CSR 选通道 + CFTW0 大端4字节)字节序/寄存器序列未上板验证 | 用逻辑分析仪看 SPI 写出的 FTW;或先用驱动 float 路径 `Reconstruct_setFreqHz` 对比 |
| 6 | 块边界相位抖动 | `SigAcq_capture`/`captureDual` 的 FIFO flush(disable/enable FIFO)清空语义/时序未上板验证(ACQ-4) | 看连续两块拼接处有无陈旧样本;必要时改成读空 FIFO 或加 settling 等待 |
| 7 | 采集偶尔不返回(已加超时兜底) | DMA_DONE 中断没触发(NVIC/中断号/向量),或定时器没在跑 | 已加 50ms 硬超时(`H_ACQ_TIMEOUT_MS`)不再死等,超时则该帧遥测显示异常 ADC 统计(min==max 或全 0)→ 据此查 `ADC0/1_INT_IRQn`、`NVIC_EnableIRQ`、DMA 触发源、`TIMER_ADC` 是否使能 |

## 遥测速查(串口每行字段)
`F=`帧号 `S=`阶段 `b=`是否建链 `C=`混合信号ADC `min/mean/max` `FB=`反馈ADC `min/mean/max`,
之后每路 `|i f=`频率 `w=`波形(S正弦/T三角) `a=`幅度 `k=`峰bin(原始,未吸附,可反算fs) `ph=`原信号相位° `v=`有效 `o=`谐波重叠 `e=`PLL相位误差° `L=`锁定 `ftw=`频率字。
- 采集对不对看 `C`:均值≈2048、不贴 0/4095、min≠max。
- 锁定看 `L=1` 且 `e` 收敛到 ~0;发挥②看两路 `ph` 之差。
- 抽稀:默认每 8 周期一行(`H_TEL_DECIM`),因 115200 阻塞发整行≈13ms;精细计时可临时关遥测或提波特率。

## 串口屏 TJC4827X243_011C 接入(结果 + 实时波形 + 触摸调相位 + 多页)
> 屏:淘晶驰 X2 系列,4.3″,480×272,电容触摸。固件经 **UART1 双向**:结果页只发变化字段;波形页 `addt` 透传;触摸/相位经 RX 中断解析。协议已对官方 wiki 高置信核验,离板 test_tjc_hmi **46/46**(含解析状态机)。开关在 `app/h_config.h`:`H_TJC_DISPLAY`(总)/`H_TJC_WAVE`(波形)/`H_TJC_TOUCH`(触摸)。

**① 接线**(引脚见 syscfg 生成宏,按番茄派丝印确认)

| MCU(UART1) | 默认引脚 | 接屏 |
|---|---|---|
| TX | PA17 | 屏 RXD |
| RX | PA18 | 屏 TXD |
| 5V / GND | — | 屏 5V / GND(共地) |

**② 波特率统一 115200**(波形需要;出厂屏默认 9600 必须改):上位机工程属性波特率 = 115200、syscfg `UART_TJC.targetBaudRate` = 115200、固件三方一致。任一不一致即乱码。

**③ 上位机(USART HMI 编辑器)搭 3 个页面**,对象名/页号**严格一致**(改名改 `tjc_hmi_core.h` 的宏):

`page 0`(主结果页):静态文字(单位 Hz/°、标题)在编辑器画、不经串口;动态值全 ASCII(避开中文 GBK 坑)。

| 对象 | 类型 | 含义 | 对象 | 类型 | 含义 |
|---|---|---|---|---|---|
| `n0` | number | A′ 频率 Hz | `n2` | number | B′ 频率 Hz |
| `n1` | number | A′ 幅度(相对)| `n3` | number | B′ 幅度(相对)|
| `t0` | text | A′ 波形 SINE/TRI | `t1` | text | B′ 波形 |
| `n4` | number | 相位差 B′−A′ (0~180°) | `t2` | text | 锁定 LOCK/UNLK |

`page 1`(波形页):放 **1 个曲线控件 `s0`**(Waveform),`ch` 属性=1(只用通道0),宽 `w` 设到能设的最大(≈对齐 `H_TJC_WAVE_N=200`,若 w 只能更小就把 `H_TJC_WAVE_N` 改成 = w),高 `h` 尽量大。MCU 仅在本页把混合信号 C 抽取缩放后 `addt` 推到 `s0`。

`page 2`(设置页·发挥②):放**滑块 `h0`**(最小0 最大180,推荐)或**加/减按钮**;在其【滑动/弹起事件】里写发自造帧:
```
printh AA 5A      // 帧头
prints h0.val,1   // 1 字节相位值(0~180)
printh 0D 0A      // 帧尾
```
MCU 解析 `AA 5A <val> 0D 0A` → 写 `s_target[1]`(相位差目标)。

> 建议每页【初始化事件】里写一句 `sendme`(屏回当前页号,MCU 据此只在波形页推流);MCU 也会周期 `sendme` 自发现,不配也能用。

**④ 下载验证**:编译工程 → 导出 → 下载到屏。`page 0` 应显示两路频率/波形,锁定后 `t2`=`LOCK`;切到 `page 1` 应看到 C 的实时波形滚动;`page 2` 拖滑块,示波器上 B′ 相对 A′ 相位差应随之 0~180° 变化。

### 串口屏「波形/触摸」上板确认项(没板子验不了,逐条抓串口/示波器确认)
> 波形显示历来是最易翻车的部分,以下按风险从高到低,带着串口助手(HEX 模式)逐条过:

| # | 必确认 | 怎么查 / 出问题怎么办 |
|---|---|---|
| 1 | **控件命令用 `.id` 不是名** | 命令里是 `s0.id`/`n0` 等;曲线/清屏/透传(add/addt/cle)**必须 `s0.id`**,用名 `s0` 屏静默无反应。`tjc_hmi_core.h` 已用 `.id`,但上位机里 `s0` 的 page 与 .id 要对得上 |
| 2 | **addt 握手时序** | 抓串口:MCU 发 `addt s0.id,0,200␏␏␏` → 屏应回 `FE FF FF FF`(就绪)→ MCU 连发**恰好 200** 个裸字节 → 屏回 `FD FF FF FF`(完成)。固件等就绪用 `H_TJC_WAVE_TIMEOUT_MS=50ms` 超时兜底(就绪没来则放弃本帧,屏未进透传态、安全) |
| 3 | **少发字节会卡死透传态**(官方称会) | 固件严格发满 `H_TJC_WAVE_N` 字节。若上板发现屏卡住(后续指令乱),抓字节确认是否真因少发;必要时在 `Tjc_pushWave` 发完追发 `\x01␏␏␏` 兜底踢回指令态 |
| 4 | **就绪延迟实际上限** | 文档给"约5ms",缓冲积压更久。若 50ms 超时频繁触发→波形断续,加大 `H_TJC_WAVE_TIMEOUT_MS`;若 addt 整条验不通,置 `H_TJC_WAVE_USE_ADDT=0` 退回 `add` 逐点 + 调小 `H_TJC_WAVE_N`(30~50,慢但确定) |
| 5 | **跨页 addt 无效** | 必须在波形页才推。固件用 `sendme`→`0x66` 跟踪当前页;若切页后没波形,抓 `66 <page> FF FF FF` 看 MCU 是否收到正确页号 |
| 6 | **触摸/相位帧** | 滑块/按钮事件里 `printh`/`prints` 发的帧:抓串口确认就是 `AA 5A <val> 0D 0A`(尤其 `printh` 是否自动加了别的尾字节,资料有分歧)。与设计不符只需改 `tjc_hmi_core.c` 解析状态机尾部,不动协议主体 |
| 7 | **波特率三方一致 115200** | 出厂屏 9600,工程属性/ syscfg / 固件都要 115200,否则乱码或 addt 跟不上 |
| 8 | 波形量程 | 固件按每块 min/max 自动量程缩放到 0~255;若波形贴顶/贴底,确认 `s0` 控件 `h` 够高、`dis` 缩放=100% |

固件侧能离板验的(已验,46/46):指令字节、scale 缩放边界、抽取降采样、解析状态机喂任意字节序列(含半截帧/噪声)不挂死且正确交付。

## 锁相主线:模拟鉴相 + PID(学长思路,`H_LOCK_METHOD=H_LOCK_ANALOG_PID`)
> 这是当前主线(H_LOCK_METHOD 默认值);与替代的数字 PLL 互斥, 改 `app/h_config.h` 一个宏即可切换、上板 A/B 对比。两模式已各自编译零告警、`test_pid` 离板 6/6。
> 思路:外部模拟乘法器把 原信号 × AD9959 正交本振 → 直流电压(=相位误差),ADC1 读它,float PID 微调 DDS 频率把相位拉到正交锁定。**固件更简单**(无双ADC同步/无第二次FFT/无atan2),复杂度在模拟硬件。

**① 切换**:`#define H_LOCK_METHOD  H_LOCK_ANALOG_PID`(现默认值;切回替代用 `H_LOCK_DIGITAL_PLL`),重新编译烧录。

**② 硬件(你来搭)**

| 模块 | 接法 |
|---|---|
| AD9959 4 通道 | CH0/CH1 = 输出 A'/B'(经重构LPF+运放到示波器);**CH2/CH3 = 正交本振**(同频, 相位差由固件控)给乘法器 |
| 模拟乘法器 ×2 | A 路:原信号A × CH2 → LPF → 鉴相电压A;B 路:原信号B × CH3 → LPF → 鉴相电压B(乘法器如 AD835/MC1496/模拟开关混频)|
| 鉴相电压 → ADC1 | 两路鉴相直流电压接 ADC1 两个通道(代码占位 `H_PD_CHAN_A/B`、`H_PD_PIN_A/B_IOMUX`,见 `sig_acq.c`,按你接线改)|

**③ bring-up(配合分阶段 H_STAGE + 遥测)**
- [ ] 先 `H_STAGE=1`:遥测看 `C` ADC 正常(同数字模式)。
- [ ] `H_STAGE=2`:测频/波形正确(分析路两模式一样)。
- [ ] 标定 **PDOffset**:不接环路,给 A/B 同频,示波器/万用表量乘法器输出在正交时的直流电压,写回 `H_PD_OFFSET_V`(默认 1.65V)。
- [ ] `H_STAGE=4` 闭环:遥测 `ftw=` 字段在模拟模式借显鉴相电压(mV),`L=` 为 PID 锁定。看 A'/A、B'/B 是否同频稳定。
- [ ] 整定 PID:从 `H_PID_KP_50K/KI_50K`(默认 2.0/1.0)起,增益已按频率调度(`H_PID_GAIN_PER_HZ`);抖→减小, 太慢→加大。`H_PID_OUT_MAX`(默认50Hz)限制频率微调范围。
- [ ] 发挥②:屏触摸/编码器设相位差 → 固件加到 CH3 正交本振相位(`s_phase_deg[1]`);量 B'/A' 实际相位差, 符号/刻度不对就调 CH3 相位映射。
