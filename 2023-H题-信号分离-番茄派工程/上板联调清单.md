# 2023 H题 — 番茄派上板联调清单

> 板子到手后照此逐项验证。代码侧(采集/分析/重建)已离板验证过,**上板主要是标定 + 硬件 + 闭环调参**。
> 勾选式推进;每项标了"为什么"和"怎么判通过"。

## 0. 前提
- [ ] CCS 导入工程(`代码/H_SignalSep.projectspec`)能 Build + 下载(见 `代码/README.md`)。
- [ ] 番茄派、AD9959 模块、运放(NE5532/OPA)、示波器、(可选)信号源/万用表就位。

## 1. 硬件搭建
- [ ] **加法器(基本①)**:NE5532 做增益 1 加法器 `C=A+B`,参考 `培训资料/NE5532缓冲&放大板.pdf`。
- [ ] **C 输入调理**:把 C 调到 ADC 量程(0~3.3V,直流偏置到 ~1.65V/中点);加抗混叠 LPF(截止 ~150–200kHz)。
- [ ] **AD9959 输出**:重构 LPF + 运放缓冲,A'/B' 各 ≥1Vpp 驱动示波器(见 `AD9959-DDS信号源资料/02-硬件接口与电路设计.md`)。
- [ ] **三角波电路(发挥①)**:AD9959 正弦 → 比较器整型成方波 → 积分器成三角波 → 幅度补偿(AD603/数字电位器)→ 模拟开关切换正弦/三角(培训3 PPT 思路)。

## 2. 上电(有坑)
- [ ] **AD9959 模块先于单片机上电**(否则其 25M→500M PLL 时钟错,输出频率不对;学长 README 明确警告)。
- [ ] 确认 AD9959 PLL 配成 **500MHz**(驱动 `ACC_FRE_FACTOR=8.589934592` 即按 500MHz;若模块实际不是 500M,改这个因子)。

## 3. 基础联调:采集 + 标定
- [ ] **确认 ADC 引脚**:`代码/app/sig_acq.c` 现用 `DL_ADC12_INPUT_CHAN_2 = PA25`。对照番茄派丝印,把 C 接到该引脚;不符就改 `H_ADC_CHAN`/`H_ADC_PIN_IOMUX`/`H_ADC_INST`。
- [ ] **采集验证**:给 C 一个已知正弦,调试器里看 `s_buf[]`(或 DAC 回放/串口打印),确认波形完整、**无削顶**(在量程内)、无明显噪声。
- [ ] **⭐ fs 标定**(关键!):给一个**已知频率**(如 50kHz)正弦,跑分析看它落在第几个 bin `k`,反算真实 `fs = 已知频率 × N / k`(N=1024)。把结果写回 `代码/app/h_config.h` 的 `H_ADC_FS_HZ`。
  - 现值标称 1.024MHz(由 SYSOSC 32MHz + 采样窗 17 周期估算,**未必精确**)。标定后频率才准。
  - 若想严格锁率,可改 TIMG 事件触发(见 `sig_acq.c` 注释的 TODO,侦察已备 API)。

## 4. 分析验证(`sig_analysis`)
- [ ] 固定输入(如 50k 正弦 + 100k 正弦),看 `h_result_t`:`freq_hz` 对不对、`wave` 对不对。
- [ ] 换三角波,确认 `wave` 判为三角;换 fB=3·fA(如 10k+30k、20k+60k)确认仍判对(5 次谐波回退已离板验证)。
- [ ] 若波形判别阈值不准,调 `sig_analysis_core.h` 的 `SIGCORE_HARM_THRESH`(现 40)。
- [ ] (已加汉宁窗:离 bin 频率误差离板实测 ±53Hz;在 bin 精确。)

## 5. 重建验证(`reconstruct`)+ MATHACL 相位刻度
- [ ] 按分析结果让 AD9959 出 A'/B',示波器量频率/幅度对不对(频率应与原信号一致)。
- [ ] **⭐ 确认 MATHACL 相位刻度**:`Recon_angleQ31ToCpow` 假设 ARCTAN2 输出"0x40000000=90°"(侦察从 SINCOS 例程推得,**未在硬件确认**)。给一对已知相位差的输入,看重建相位是否对;若刻度不同,只需改该函数的移位位数(现 `>>18`)。
- [ ] FTW/CPOW 换算本身离板已验证(18/18),频率/相位差数值无需再怀疑,重点是上面这条刻度假设。

## 6. 同频稳定显示(核心难点)+ PLL 闭环
- [ ] **先开环看漂移**:重建 A' 后,示波器对比 A'/A —— 因信号源与 AD9959 晶振独立,会缓慢相对漂移(培训3 PPT 指出)。
- [ ] **接 PLL**:`pll.c` 是定点 PI;`h_app.c` 闭环现为相位微调骨架。上板要:
  - 鉴相改为 **A' 与 A 的真实相位差**(当前用的是 C 的绝对相位,需改成误差)。
  - 稳态后切到**调 FTW 的带预调谐 PLL**:`FTW = 目标频率预设 + 环路输出`(PPT 要点)。
  - PI 参数 `Pll_init` 的 kp/ki 随频率按比例缩放;**控制周期固定**(`h_app` 里 `Tick_delay` 已固定)。
- [ ] 判通过:A'/A、B'/B 在示波器上**长时间稳定不漂**。

## 7. 发挥①:三角波
- [ ] 分析判出三角时,走三角波硬件链(§1),示波器看 A'/B' 为三角、无明显失真。

## 8. 发挥②:相位差控制
- [ ] 用 `Reconstruct_setPhaseDiffDeg(idx, ref_cpow, deg)` 设 B' 相对 A' 的相位差(0~180°,5° 步进)。
- [ ] 示波器量实际相位差,确认误差 ≤5°(换算分辨率离板实测 0.0098°,主要看硬件/刻度)。

## 9. 逐条对照题目验收
- [ ] 基本①:增益 1 加法器 C=A+B。
- [ ] 基本②:A、B 正弦 fA=50k/fB=100k,分离 A'/B' 峰峰值 ≥1V。
- [ ] 基本③:A、B 正弦、10kHz 整数倍,正确分离。
- [ ] 发挥①:A、B 正弦/三角、5kHz 整数倍,正确分离。
- [ ] 发挥②:fB 为 fA 整数倍时,B'/A' 相位差 0~180°、分辨率 5°、误差 ≤5°。

## 10. 待硬件确认的假设(汇总)
1. **fs 实际值**(§3 标定)——影响所有频率读数。
2. **ADC 引脚**对应番茄派哪个排针(§3)。
3. **MATHACL ARCTAN2 相位刻度**(§5)——影响相位/同频对齐。
4. **AD9959 PLL=500MHz**(§2)——影响输出频率。
5. **采样窗/ADC 时钟**能否稳定支撑该 fs(§3);必要时改采样时间或上 TIMG 触发。
6. 波形判别阈值 `SIGCORE_HARM_THRESH`(§4)实测微调。
