# 2023 H题 信号分离装置 —— 番茄派实物工程

> 我们队的 **H题实物工作区**(2026 备赛 · 番茄派 MSPM0G3507)。**只放代码与必要说明**(硬件原理图/测试数据/报告等不入库)。
> 任务来源:学校第三次培训(`任务-2026北京电设培训3.pptx`,周润华老师,2026-06-12)。

## 🎯 目标
番茄派实物完成 2023 H题:`C = A + B`(20–100kHz,5kHz 步进,1Vpp,正弦/三角)→ 分离出 A'/B' → 示波器**同频稳定显示** + **相位调节**。

## 总体方案(培训3 PPT + 队内讨论)

**选「再生法」**(DDS 重建)—— 计算量小、单片机可控、相位调节简单(培训 PPT 明确推荐,也最契合我们已有的 AD9959)。
- **分工**:MSPM0 番茄派负责"看懂 C"(FFT 分析频率 + 波形 + 相位);**AD9959 负责"重画 A'/B'"**。
- **H题是基带直采**(20–100kHz):番茄派 ADC 4MSPS 直采 C,**不需要混频/本振**(和 D题不同)。

### ① 信号分析(确定频率 + 波形)
- **参数(PPT 给的可行值)**:`fs = 1.024 MSa/s,N = 1024 → 频率分辨率 1kHz`。
  - 依据:要分辨到 100kHz 三角波的 5 次谐波 → fs 需 > 1MSa/s;fRes < 5kHz;N 取 2 的幂。
- FFT(**ARM DSP 库 / CMSIS-DSP,定点 q15**)+ 复数模值 + 寻峰/排序 → 两个频率;3/5 次谐波能量比 → 正弦/三角。
- ⚠️ **M0+ 无 FPU**:相关/FFT 用定点;`sqrt / atan2 / div` 走 **MATHACL** 硬件加速;相关累加器用 **int64**(防溢出)。

### ② 再生 + 稳定显示(本题最关键)
- **漂移真相(PPT 纠正了"设精确频率就不漂"的乐观看法)**:信号源的晶振与 AD9959 的晶振**相互独立**,"同频"输出其实有细微频率误差 → **会漂**。光设精确频率不够。
- **解决 = 软件锁相环(PLL)**:把 AD9959 输出锁到参考信号 C(AD9959 当 NCO,FTW 控频)。
  - **带预调谐**:`FTW = 预设值(目标频率) + 环路输出值`(PLL 难锁大范围,先预置目标频率)。
  - **鉴相**:乘法器 / IQ 解调取相位差;**环路滤波**:PI 控制器,**P/I 随频率按比例缩放**更易锁。
  - **反馈环路的控制时间间隔必须固定**。
  - 备选(方案1):现场微调 FTW 校准频率(AD9959 主频 500MHz 时分辨率 0.12Hz)。简单但 PPT 说不通用、**不推荐**。

### ③ 三角波怎么出(PPT 给了干净解法,比谐波合成强)
- AD9959 只出正弦 → **比较器把正弦整型成方波 → 积分器把方波转成三角波**。
- ⚠️ 积分出的三角波**峰峰值随频率变**:直接出足够大,或按频率控方波幅度(**AD603 / 数字电位器**)补偿。
- 用**继电器 / 模拟开关**切换正弦/三角输出。

### ④ 加法器(基本①)
NE5532 做增益 1 加法器 + C 输入调理(参考 `../培训资料/NE5532缓冲&放大板.pdf`)。

### 三种分离思路对比(PPT,留作备选)
| 思路 | 做法 | 优势 | 代价 | 取舍 |
|---|---|---|---|---|
| 时域滤波 | FIR 一两百阶,系数重载/滤波器组 | 输出稳定不漂移;留高次谐波则三角直接出 | 阶数高,FPGA+高速 AD/DA | 备选 |
| 频域滤波 | FFT 重叠相加/保留法 | 顺带有频域数据;输出稳定;三角直接出 | 计算量大,需 DSP/FPGA | 备选 |
| **再生法** ✅ | DDS 重建两信号 | **计算量小、单片机可控、相位调节简单** | 要解决漂移(PLL)+ 三角(整型积分) | **我们选这个** |
