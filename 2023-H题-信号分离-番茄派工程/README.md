# 2023 H题 信号分离装置 —— 番茄派实物工程

## 目标
番茄派实物完成 2023 H题:`C = A + B`(20–100kHz,5kHz 步进,1Vpp,正弦/三角)→ 分离出 A'/B' → 示波器同频稳定显示 + 相位调节。

## 总体方案(培训3 PPT + 队内讨论)

选「再生法」(DDS 重建)—— 计算量小、单片机可控、相位调节简单(培训 PPT 明确推荐,也最契合我们已有的 AD9959)。
- 分工:MSPM0 番茄派负责"看懂 C"(FFT 分析频率 + 波形 + 相位);AD9959 负责"重画 A'/B'"。
- H题是基带直采(20–100kHz):番茄派 ADC 直采 C(实际 fs≈1.0256MSa/s,定时器触发;ADC 硬件可达 4MSPS),不需要混频/本振(和 D题不同)。

### ① 信号分析(确定频率 + 波形)
- 参数(PPT 给的可行值):`fs = 1.024 MSa/s,N = 1024 → 频率分辨率 1kHz`。
  - 依据:要分辨到 100kHz 三角波的 5 次谐波 → fs 需 > 1MSa/s;fRes < 5kHz;N 取 2 的幂。
- FFT(ARM DSP 库 / CMSIS-DSP,定点 q15)+ 复数模值 + 寻峰/排序 → 两个频率;3/5 次谐波能量比 → 正弦/三角。
- 注意 M0+ 无 FPU:相关/FFT 用定点;`sqrt / atan2 / div` 走 MATHACL 硬件加速;PLL 积分累加器用 int64(防溢出)。

### ② 再生 + 稳定显示(本题最关键)
- 漂移真相(PPT 纠正了"设精确频率就不漂"的乐观看法):信号源的晶振与 AD9959 的晶振相互独立,"同频"输出其实有细微频率误差 → 会漂。光设精确频率不够。
- 解决 = 软件锁相环(PLL):把 AD9959 输出锁到参考信号 C(AD9959 当 NCO,FTW 控频)。
  - 带预调谐:`FTW = 预设值(目标频率) + 环路输出值`(PLL 难锁大范围,先预置目标频率)。
  - 鉴相:原信号相位 与 重建信号实测相位 之差(反馈由第2路 ADC 采 A'+B' 得到);环路滤波:II 型 PI 控制器。
  - 反馈环路的控制时间间隔必须固定。
  - 两路 ADC(C 与反馈)已改 **定时器(TIMA0)事件同时触发** → 零时间差,鉴相干净(发挥②相位差≤5° 的关键);测得频率 **吸附到 5kHz 网格**,DDS 输出精确网格频率,PLL 只拉两晶振 ppm 级差。
  - 现状:PLL 算法 + 反馈相位提取代码已就绪并离板验证,上板需接反馈通道 + 整定增益;**串口遥测可实时看 perr/锁定/FTW**。
  - **锁相两条路线可切**(`H_LOCK_METHOD`):**数字PLL**(替代)/ **模拟鉴相+PID**(主线·默认;学长思路:外部乘法器鉴相 → ADC → PID 调频;AD9959 用4通道正交本振)。上板可 A/B 对比,详见 `上板联调清单.md`「锁相方式二」。

### ③ 三角波怎么出(PPT 给了干净解法,比谐波合成强)
- AD9959 只出正弦 → 比较器把正弦整型成方波 → 积分器把方波转成三角波。
- 注意:积分出的三角波峰峰值随频率变:直接出足够大,或按频率控方波幅度(AD603 / 数字电位器)补偿。
- 用继电器 / 模拟开关切换正弦/三角输出。

### ④ 加法器(基本①)
NE5532 做增益 1 加法器 + C 输入调理(参考 `../培训资料/NE5532缓冲&放大板.pdf`)。

### 三种分离思路对比(PPT,留作备选)
| 思路 | 做法 | 优势 | 代价 | 取舍 |
|---|---|---|---|---|
| 时域滤波 | FIR 一两百阶,系数重载/滤波器组 | 输出稳定不漂移;留高次谐波则三角直接出 | 阶数高,FPGA+高速 AD/DA | 备选 |
| 频域滤波 | FFT 重叠相加/保留法 | 顺带有频域数据;输出稳定;三角直接出 | 计算量大,需 DSP/FPGA | 备选 |
| 再生法(选用) | DDS 重建两信号 | 计算量小、单片机可控、相位调节简单 | 要解决漂移(PLL)+ 三角(整型积分) | 我们选这个 |
