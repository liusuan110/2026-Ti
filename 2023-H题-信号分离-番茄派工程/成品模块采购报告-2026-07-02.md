## 2. 与 2023 H 题方案的对应关系

本次采购明显围绕“模拟前端 + 鉴相闭环 + 上板可调试”展开, 与当前 H 题工程默认主线 `H_LOCK_ANALOG_PID` 匹配。

### 2.1 混合与重建前端

- 高速加法器模块可直接用于生成基本题要求的 `C = A + B` 混合信号, 也可用于快速替代自焊加法器验证软件分析链路。
- NE5532、OPA847、AD817 模块可以覆盖低频/中高频缓冲、放大、反相和阻抗匹配需求。
- AD603 可作为可调增益或 AGC 实验模块, 对幅度归一化、输出幅度补偿和三角波链路调幅有参考价值。

### 2.2 模拟鉴相与闭环

- AD835 乘法器模块是模拟鉴相主链路的关键件: `输入信号 x AD9959 正交本振 -> 低通 -> 相位误差电压`。
- UAF42 可调滤波模块可用于鉴相乘积后的低通滤波实验, 帮助确定截止频率、响应速度和纹波折中。
- 直流偏置可调放大器可用于把鉴相电压或 ADC 输入调理到 MSPM0 ADC 可接受范围, 特别是围绕 1.65 V 中点工作。

### 2.3 供电与切换

- 单电源转正负 5V 模块用于快速给 AD835、UAF42、运放类模块提供双电源验证环境。
- 5V 继电器模块可用于实验阶段的信号路径切换、电源隔离或正弦/三角波路径切换, 但正式方案中要评估继电器速度、触点噪声和可靠性。

## 3. 上板前检查清单

1. 确认每个模块的供电范围、输入/输出摆幅、带宽和接口电平, 特别是 AD835、UAF42、AD603、OPA847。
2. 所有进入 MSPM0 ADC 的信号必须限制在 0-3.3 V, 并优先偏置到约 1.65 V 中点。
3. 鉴相链路建议先离线验证: AD9959 正交本振 -> AD835 乘法 -> UAF42/RC 低通 -> 偏置放大 -> ADC1。
4. 用示波器逐级确认幅值、偏置、削顶、噪声和相位关系, 不要一开始就闭环。
5. 将 `sig_acq.c` 中 ADC1 鉴相/反馈通道占位宏改成实际接线。
6. 上电前确认 +/-5 V 模块负载能力和纹波, 模拟模块与 MCU 必须共地。
7. 若继电器用于信号路径, 先验证切换瞬态是否会打到 ADC 或 AD9959 输出端。

## 4. 建议联调顺序

1. 只接电源模块和示波器, 验证 +/-5 V 稳压、纹波和负载余量。
2. 用函数发生器给高速加法器/NE5532/AD817, 验证加法、反相、缓冲和幅度范围。
3. 单独验证 AD835 鉴相: 输入同频正交/同相两路信号, 观察乘法后低通直流电压变化。
4. 加入 UAF42 或 RC 低通, 找到鉴相电压稳定性与响应速度的折中。
5. 用直流偏置模块把鉴相电压调到 ADC 安全范围, 记录零相位或正交点偏置值。
6. 接入 MSPM0 ADC1, 先只看遥测电压, 再启用 `H_STAGE=4` 闭环。
7. 最后接入 AD603/三角波链路/继电器切换等发挥项。

## 5. 风险与注意事项

- 成品模块接口命名、带宽和实际性能可能与商品标题不完全一致, 到货后要以实测为准。
- AD835/UAF42/OPA847 等高速或模拟精密模块对供电、布局、共地和负载比较敏感, 杜邦线过长会明显引入噪声和振荡风险。
- UAF42 截图规格显示 300 Hz-15 kHz, 若用于 50 kHz/100 kHz 相关链路, 只能用于鉴相后的低频误差滤波, 不适合直接滤除载频信号。
- 继电器适合低速切换, 不适合高速模拟信号的实时调制。
- 当前采购清单偏向“快速验证模块”, 最终参赛板仍应把关键链路收敛成稳定、可固定参数的电路。
