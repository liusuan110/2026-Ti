# 历年三类原题题库(2015–2025)

> 来源:社区归档 [CCBP/NUEDC_Topic](https://github.com/CCBP/NUEDC_Topic);原题版权归全国大学生电子设计竞赛组委会,仅供团队备赛研读。
> 整理:2026-06-06 · 共 22 道三类原题 + 4 份器件清单 + `Classification.xlsx`(官方分类表)。

## 说明
- **偶数年(省级/模拟专题赛)** 不在此(国赛只在奇数年);偶数年赛题与开源见本仓 `偶数年专题赛与省级赛-赛题与开源方案.md`。
- 已排除明显非三类的题(如 2025 B 单相有源电力滤波=电源类);标注"(相关)"的为电参数测量类,与功率分析/测量方向相关,一并收录。
- `Classification.xlsx` 为 CCBP 归档的官方题目分类表,可按类快速检索更多年份。
- 综述与命题规律见本仓 `电赛三类赛题分析与备赛资料.md`。
